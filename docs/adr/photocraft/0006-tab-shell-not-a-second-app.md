# ADR 0006：标签页是编辑器本体，宿主席位只留一条外壳

- 状态：提议（2026-11-02，取代同一编号的「Cockpit 不是镜像」草案）
- 关联文档：[0001](./0001-the-tab-runs-upstreams-web-build.md)、[0003](./0003-only-input-and-save-are-visible.md)

## 1. 背景

0001 定了「iframe 里是上游的 Photocraft」。随之而来的问题是**它周围还要不要东西**。两个极端都不对：

- 全裸：只有 iframe。加载失败、Payload 未就绪、浏览器下载降级时，用户面对一块白屏，没有出路。
- 包一层：自己做工具栏、自己的打开/保存按钮、自己的图层列表——那是「重新开发一套」的开始，
  而且会和编辑器自己的界面打架（同一件事两个入口、两份状态）。

## 2. 决策

**D1 外壳只有一条 28 px 的信息条**，内容全部是**事实**，不含任何会与编辑器重复的操作：

| 位置 | 内容 |
| --- | --- |
| 左 | 绑定的文件名（无绑定时「新建文档」） |
| 中 | 最近保存时间 / 「此后有输入」；从磁盘被改过时的提醒 |
| 右 | 后端标记 `GPU`/`GL`/`CPU`、`重新载入`、`在浏览器打开`（内置面板 / 系统浏览器两个入口，见 [0007](./0007-one-loopback-hub-three-entries.md)） |

**D2 不复制编辑器的任何控件**。没有自己的打开/保存按钮（用编辑器菜单里的），没有工具条，没有图层面板，
没有第二套撤销。除了 `重新载入`，外壳上每个按钮都是**逃生口**（打不开时的出路），不是编辑器功能的替代品。

**D3 iframe 贴边铺满**：无内边距、无卡片阴影、无圆角，`width:"max"` + `retention:"pinned"`。

**D3b 这条外壳只存在于宿主标签页**。同一个 URL 在宿主内置浏览器面板和系统浏览器里打开时，上面那条
信息条**不存在**，用户看到的就是上游页面本身——没有我们的按钮、没有后端标记、也没有「重新载入」。
这不是遗漏：那两个位置没有插件的 React 树，也就没有地方放它；同时也意味着在那两个入口里，
「保存回工作区」与「磁盘被改提醒」两项能力不存在（0002 D6、[0007](./0007-one-loopback-hub-three-entries.md) D3）。
编辑器自己的边框就是面板的边框；视觉上当它是宿主的一部分，而不是「宿主里嵌了一个网站」。

**D4 不试图给编辑器套主题。** Photocraft 有自己的主题与配色，我们不去覆盖它（覆盖会随上游改版失效，
且用户在编辑器里的偏好设置应该说话）。承接点在信息条的下边线：一条 1 px 的分隔线，让「宿主的」和
「它的」有一个明确边界。

**D5 键盘交给 iframe。** 标签页激活时，插件不注册全局快捷键、不 `preventDefault`；编辑器自己的
`Cmd+Z`、空格平移、`B` 画笔都是它的事。宿主级的快捷键（切标签、关面板）由宿主处理，插件不插手。

**D6 空态与错误态必须是可读的一屏**，不是一句 `console.error`：

| 状态 | 一屏内容 |
| --- | --- |
| Payload 未就绪 | 进度条 + 「正在准备编辑器（约 20 MB，仅首次）」 |
| 下载失败 | 重试 / 我有 zip / 在浏览器打开 |
| 后端不可用 | 「这台机器的 Chromium 无法运行 Photocraft」+ 诊断三元组（有无 WebGPU/WebGL2/CPU） |
| 已降级为浏览器下载 | 「这个文档太大，已改为浏览器下载」+ 下载落点提示 |

## 3. 后果

- **好处**：宿主的维护面极小——升级编辑器是换 zip，不是改 React；用户看到的是他熟悉的 Photocraft。
- **代价**：宿主与编辑器在视觉上必然有缝（两套主题、两种字体）。D4 选择「承认缝」而不是「抹平缝」，
  因为抹平的成本会随上游每次改版重付一遍。
- **风险**：`重新载入` 会丢弃 iframe 里的一切（包括撤销栈）。它必须走 0003 D2 的确认，不能是一个
  无保护的按钮。

## 4. 证据与未验证

Observed：活动面板标签页的 `width:"max"` 与 `retention:"pinned"` 契约（`plugin-sdk/src/ui.ts`）；
`useActivityTab()` 提供 `active`，可用于「切走时是否暂停」这类判断。

未验证：面板宽度到 `max` 时在一台 13 寸笔记本上的实际可用像素（未实测，实现时量一次，决定要不要
提供一个「弹出为浮窗」的入口）。
