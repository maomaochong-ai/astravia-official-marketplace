# strix-0007 — 面板是仪表盘，不是第二份对话

- **Status:** Accepted
- **Date:** 2026-11-14
- **Context:** 插件 strix 0.7.1；0.7.0 引入 33 个工具后，用户反馈「对话区的回复和插件的回复是一样的，感觉冗余」
- **Related:** [0003](strix-0003-panel-reuses-host-and-subagents.md)（一个 AI：宿主会话即循环）、
  [0004](strix-0004-panel-is-a-workbench.md)（面板是一张工作台）

## The situation

0003 定下「宿主会话是唯一的循环」，于是面板不再自己推理。为了让面板"跟得上"，0.6.0 让它
订阅对话事件并把文字画出来：

| 面板里的东西 | 来源 | 实际上是什么 |
|---|---|---|
| `You: …` 行 | `message-added`（`role: "user"`） | 用户刚在聊天区说过的话 |
| 一整段 agent 回复 | `message-added`（`role: "assistant"`） | 聊天区里同一段话，且那边有 markdown |
| 逐字流式正文 | `message-updated` 的 delta | 同上，实时版 |
| 面板输入框发出的话 | 本地 `pushTrace({kind:"user"})` | 聊天区马上会显示同一句 |
| 工具块 | `tool-call-*` / 服务事件 | 命令、退出码、耗时、输出尾巴 |

前四行是**同一段文字的第二次渲染**：信息量为零，代价是三个——两个可滚区域让人不知道看哪个、
读者会以为有两个 agent 在说话、以及面板真正独有的东西（证据、台账、状态）被淹没在散文里。

## The decision

**对话是说话的地方，面板是看现场的地方。** 一条界，四种内容各归其位：

| 内容 | 归属 | 理由 |
|---|---|---|
| 用户说的话、agent 的回复 | **对话** | 聊天区已经渲染得更好（markdown、可复制、可回溯）；再写一遍不产生信息 |
| 命令原文、退出码、耗时、输出尾巴 | **面板** | 聊天区的工具卡片没有这些；而且它会被滚走 |
| 沙箱/会话/范围/计划/覆盖/台账/MCP | **面板** | 聊天区没有"现在是什么"的概念，只有"说过什么" |
| 轮次边界 | **面板**（一行分隔） | 给现场一个时间锚点：`第 3 轮 · 这一轮说了什么在对话区` |

落到代码：

1. `TraceEntry.kind` 从 `"tool" | "say" | "user" | "note" | "host" | "host-say"` 收窄到
   `"tool" | "say" | "note"`。**类型里没有这两个名字，就抄不了**——这比写一条注释可靠。
2. `hostRowFor()` 删除，改为 `turnDivider(turn, label)`：只产编号分隔行，不产正文。
3. `use-strix-session` 对 `message-added` / `message-updated` **显式 return**（带注释说明这是
   决定不是遗漏），只处理 `turn-start` / `turn-end` / `tool-call-*`。
4. 面板输入框发出的那句话不再本地回显：它落在对话里，那里是它的位置。
5. 轨迹栏标题改为「运行记录 · 命令与结果」，输入框提示改为「从这里发出也会进对话区；面板
   不重复显示文字，只记命令与结果」。

## Considered options

- **保留镜像，但折叠**（默认收起 agent 回复）。改动小，但仍然是同一份内容存在两次；而且"要不要
  展开"变成一个新的认知负担。**否。**
- **面板只做只读仪表盘，删掉输入框。** 最彻底，但用户在面板里看完证据想追一句"继续深挖"时
  必须切回聊天区，把操作割裂成两个窗口。**否**——保留输入框，但它是**投递口**，不是聊天窗。
- **面板自己再调一次模型生成"摘要"**。那是第二份推理，正是 0003 已经否掉的东西。**否。**

## What this does not do

- 不删工具块：`strix_exec` 的命令与输出仍在面板，那是对话区没有的信息。
- 不删 `note`：沙箱阶段、越界提示、会话起止、补丁落地、`strix_think` 都在这里，对话区没有。
- 不承诺面板与对话"内容一致"——它们**不应该**一致：一个记录说过什么，一个记录做了什么。

## The cost

- 面板单独看会显得"安静"：一轮里如果 agent 只说话不跑命令，那条轨迹上只有一行分隔。
  这是正确的信号（这一轮没有产出证据），但对习惯读日志的人需要一句解释——所以分隔行本身
  就写着"这一轮说了什么在对话区"。
- 无法在面板里回看历史对话的原文。要回看就去聊天区：它本来就在那里，而且带 markdown。
