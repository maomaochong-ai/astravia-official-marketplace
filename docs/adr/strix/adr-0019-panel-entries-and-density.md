# ADR 0019：面板的入口与密度

- **状态：** 已接受
- **日期：** 2026-11-15
- **背景：** 插件 strix 1.0.11；用户要求「原型图需要看清楚每个入口细节」，并据此重做一版 UI
- **关联：** [ADR 0004](adr-0004-panel-is-a-workbench.md)（工作台形态）、[ADR 0007](adr-0007-panel-is-a-dashboard.md)（不是第二份对话）、
  [ADR 0008](adr-0008-three-roles-of-the-panel.md)（证据 / 台账 / 控制）、[ADR 0009](adr-0009-ui-baseline-is-upstream-tui.md)（TUI 基线）、
  [ADR 0016](adr-0016-team-members-are-declared-not-spawned.md)（团队成员）

## 现状

到 1.0.11，面板已有 21 处可交互入口（原型 `strix-panel-v2.html` 逐个编号）。它们来自五次加法，
每次单独看都合理，合起来出现三个问题：

1. **首屏不告诉用户"谁会上场"**。团队是 1.0.10 才有的能力，但它只出现在工作台的侧栏里——
   用户在首屏没有任何线索，只能被告知"插件装了团队"。
2. **侧栏被撑成一条长滚动**。八个分区（会话 / 目标 / 发现 / 计划·覆盖·笔记 / 连接 / 统计 / 团队 / 历史）
   在 `clamp(15rem, 22vw, 19rem)` 宽的栏里堆叠，滚动条比内容还长，右边一条几乎全是空白。
3. **状态带与统计栏重复**。模型名与步数在两处各写一遍；两处都是"总是可见"，于是都看不清。

## 决定

1. **首屏加「团队」行**（事实表最后一行）：四个 chip，hover 给职责，队长高亮。
   - 名字来自服务读回的 roster（manifest 声明），不是面板里写死的四个字符串；
   - 字形按**角色槽位**取（`master ◉ / researcher ◎ / developer ◈ / auditor ≡`），换人、改名都不动代码。
2. **侧栏分区标题即折叠开关**：整条标题可点，`aria-expanded` 跟着变；收起时只留「字形 + 名称 + 计数 + `+`」。
   - 默认展开"这一眼要看的"：目标 / 发现 / 统计 / 团队；
   - 默认收起"几乎不看但不能没有"的：连接 / 历史；
   - 收起用 `display: none`，不是只把视线移开——省下的是真实的布局高度。
3. **每个分区一个字形**，与工具行同一套语义：`▣` 会话、`◎` 目标、`◈` 发现、`▦` 统计、`⚉` 团队、
   `◷` 历史、`⇄` 连接。字形是"这块是什么"的最短表达，比再加一行标题便宜。
4. **状态带只留"现在在测什么"**：跑没跑、几个目标、什么深度、跑在哪、几条高危。模型与步数去统计栏。
5. **新旧两类折叠按钮不共用类名**：`panel-box` 里那颗 20px 的 `+/−` 按钮是"展开一段正文"，
   分区标题是"收起一整块"，语义不同，样式也不同。分开命名（`.astra-strix-section-toggle` 与
   `.astra-strix-section-head`），避免下次改一处坏两处。

## 为什么不是别的形状

| 做法 | 为什么没选 |
|---|---|
| 侧栏改成两列 / 网格 | 19rem 宽放两列，每列 9rem，中文小字会折行；宽度更紧的是面板而不是屏幕 |
| 用一个「更多」菜单收纳收起的分区 | 多一次点击，且菜单里看不到计数——而计数正是"要不要点开"的依据 |
| 首屏团队行改成一句话（"本次由四器小组执行"） | 名字是用户要在对话里 `@` 的东西，写成一句话就没法认人 |
| 把额度也放进状态带 | 额度是"还能做多少"，属于统计；放带里会和"几条高危"抢同一行的注意力 |

## 代价

- **首屏多了一行**：窄屏（430px）时团队 chip 会折成两排，首屏整体高度增加约 26px。
  换来的是"开始前知道谁上场"，值得。
- **侧栏多了一次点击**：默认收起的两块（连接 / 历史）要看就得点。它们是"确认一下"而不是
  "随时盯"的信息，收起是对的；但用户如果习惯了一眼看全，会觉得少了东西——这一条只能靠默认值调优。
- **字形是装饰，也是语义**：读屏会跳过它们（`aria-hidden`），所以它只帮视觉读者，不帮所有人。

## 验证

- 原型：`.tmp/prototypes/strix-panel-v2.html`（本地，不入库），逐入口编号 + 四个状态 + 键盘表。
- `test/panel-entries.test.ts`（9 项）：团队行来自 roster、字形按角色、折叠默认值、
  整条标题可点、收起真的 `display:none`、状态带不重复统计项。
- 真浏览器（`dist/style.css`）：1280 宽三栅格对齐；430 宽时团队 chip 折两排、状态带换行、
  输入框仍一行高。

## 修订

**1.0.13（[ADR 0020](adr-0020-two-kinds-of-conversation-one-boundary.md)）：六个分区，不是七个。** 「会话」那两条事实——在哪跑、
会话 id、镜像——描述的是这一轮的状态，不是独立主题，并进了「统计」；`▣` 随之退役。
首屏也多了一条不发送的入口（「工作台」），与「返回首屏」互为一对。
