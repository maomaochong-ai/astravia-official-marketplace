# strix-0016 — 团队成员：插件声明，宿主运行

- **Status:** Accepted
- **Date:** 2026-11-15
- **Context:** 插件 strix 1.0.9；用户要求「参考宿主侧边栏智能体团队 / 麻花小说插件的形式，形成合适的团队成员，装好插件就能在对话框选择团队成员」
- **Related:** [0003](strix-0003-panel-reuses-host-and-subagents.md)（一个 AI）、[0010](strix-0010-agents-panel-becomes-working-units.md)（agents 栏改成工作单元）

## 上游有什么，我们缺什么

上游 TUI 有一支自己的子智能体队伍：`tools/agents_graph` 负责派生/等待/停止，`render/agents_graph.go`
把它画成树。它成立的前提是**上游自己持有模型循环**——它要给每个子代理配模型、发消息、收结果。

本插件没有循环（ADR 0003）。所以"派生子智能体"这条我们不做；但宿主**已经有**团队成员这件事：

| 宿主能力 | 谁在用 | 我们怎么用 |
|---|---|---|
| `agent.agents`（blueprint：id/名字/头像/人设/角色） | 预置插件、麻花写作团队 | 声明四位成员，人设写成本插件的做事方式 |
| `agent.teams`（第一个成员是队长，宿主渲染成可选团队） | 同上 | 声明一支 `strix-assessment` |
| `agent.teams[].members[].role`（角色槽位） | 跨插件借用 | 声明 `master` / `researcher` / `developer` / `auditor` |
| 输入框 `@` 提及团队成员 | 宿主已实现 | 装好插件就能 @ 到侦察手/验证手/复核官 |

于是"多智能体"在本插件里的诚实形态是：**人是我们声明的，循环是宿主的**。用户点开对话框的
成员选择器，看到的是四个人；选中后仍然是宿主那个模型在跑，只是换了人设与任务书。

## The decision

1. **四个人**：`strix-lead`（master，队长，唯一对用户说话）、`strix-recon`（researcher）、
   `strix-exploit`（developer）、`strix-auditor`（auditor）。
2. **`abilities: "own"`**：成员只拿本插件的工具与技能库。给它们宿主全部能力，就等于在插件里
   又造一套 AI——那正是 ADR 0003 禁止的事。
3. **每人一份任务书**：本体人格在 `agent/agents/*.md`，团队任务书在
   `agent/prompts/team-workflow.md`，成员级补充在 `agent/prompts/briefs/*.md`。
   三者分工：人格说"我是谁"，团队任务书说"我们怎么配合"，brief 说"你在本团队怎么做"。
4. **署名进台账**：`strix_file_finding` 新增可选 `member`。服务看不到调用方身份（MCP 不带），
   所以由成员自己的任务书要求它署名；面板的「团队」栏按名册对账，对不上就不计数。
5. **面板画的是花名册，不是虚构的活动图**：成员身份来自 manifest（静态事实），署名数来自发现
   台账（动态事实）。**没有**"谁正在思考"这种我们观测不到的状态——那会是编造。

## 为什么不是"插件自己派生"

| 做法 | 能不能 | 代价 |
|---|---|---|
| 插件内 spawn 子代理并各自持模型 | 不能（无 `ctx.ai`） | 与 ADR 0003 直接冲突 |
| 插件用 `ctx.conversation.createSession` 造多个会话当"成员" | 能，但错 | 每个会话都是一个用户可见的对话，会把聊天区撕成四份 |
| **声明 `agent.teams`，宿主渲染与运行** | 能 | 成员编排由宿主做，插件只提供人设、工具与技能 |

## 已知边界

- **队长是唯一入口**：宿主文档写明"第一个成员即队长，也是用户在会话里唯一的对话入口"。
  想直接跟侦察手说话，用 `@` 提及。
- **不保证顺序执行**：团队流水线写在任务书里（先范围、后侦察、再验证、最后复核），
  由模型遵守，而不是由插件强制。插件能强制的只有工具层的门禁（覆盖收尾、预算）。
- **角色槽位可能被别人接管**：用户可以把 `researcher` 槽位改绑到别的插件的人。这是宿主设计，
  我们不拦；署名对不上时，花名册如实显示"还没有署名记录"。
