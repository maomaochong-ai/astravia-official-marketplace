# ADR 0024：背景是自绘的层，不是下载的图

- 状态：已采纳
- 日期：2026-11-15
- 关联：[ADR 0011](adr-0011-hacker-style-phosphor-rain-and-sweep.md)（磷光、数据流、扫光）、[ADR 0023](adr-0023-launch-is-honest-config-talk-and-paths.md)（首屏是配置 + 说话 + 免责）
- 取代：ADR 0011 里"背景只有黑底 + 数据流"那一半

## 背景

用户的原话是"背景除了代码流动之外需要更黑客一些，比如可以从网络下载一些黑客相关的背景图片，炫彩一些，但要和文字颜色匹配"。

诉求有两层，第二层是硬约束：

1. 背景要更"黑客"、更有色，不能只是黑底上几列绿字；
2. **颜色必须和文字匹配**——这套界面的正文是 `#a7f3d0`，任何背景都得让它保持在可读区间。

## 为什么没有真的去下载图片

"从网上找几张黑客背景图"能解决第 1 层，但会在三处付代价：

| 问题 | 具体后果 |
|---|---|
| 许可证 | 本插件随官方市场分发。任何来源不明的图都可能让整个包不能上架，或日后被要求下架 |
| 分辨率 | 面板宽度从 300px 到 1400px 都有，一张位图要么糊要么裁；再叠加高斯模糊，等于把体积花在看不见的地方 |
| 颜色不可控 | 换成别人的图之后，`#a7f3d0` 可能在暗部糊掉、在亮部发灰——第 2 层约束直接失效 |

替代方案是**自绘的层**：CSS 渐变 + 内联 SVG。颜色是我们自己的变量，所以"炫"与"匹配"可以同时成立，而且离线、确定性、零体积。

## 决定

### 1. 七层，各管一件事

| 层 | 作用 | 上限不透明度 |
|---|---|---|
| `aurora` | 三个色团（绿 / 青 / 紫）+ 一条斜向底色，26s 缓慢呼吸 | 0.5（工作台 0.2） |
| `mesh` | 8px 点阵 + 64px 主格线 | 0.12 |
| `rings` | 右下角为圆心的雷达同心环，90s 转一圈 | 0.10 |
| `sheen` | 青→紫的光带缓慢横穿 | 0.16 |
| `horizon` | 底部 42% 的透视网格（`rotateX(58deg)`），给纵深 | 0.16 |
| `vignette` | 边角压暗 48%，视线落回中间那一列字 | — |
| `grain` | 内联 SVG `feTurbulence` 噪点，掩盖深色渐变的 8bit 条带 | 0.035 |

数据流（`hacker-rain`）仍是最上面那一层"内容"，正文压在它之上；两个 z-index 规则各加了 `:not(.astra-strix-backdrop)` 例外。

### 2. 颜色只用三个变量

```
--sx-aurora-a: #10b981   /* 绿：与 --sx-green 同族 */
--sx-aurora-b: #0891b2   /* 青：右侧与网格 */
--sx-aurora-c: #7c3aed   /* 紫：底部与扫光 */
```

它们挂在 `.astra-strix-backdrop` 上，所以换主题、改磷光档都能跟着走，色值不会散进十几条规则。**深饱和、低亮度**是刻意的：拉开色相差异，同时不抬亮度——对比度守的是亮度差，不是色彩差。

### 3. 动效可关

`prefers-reduced-motion: reduce` 下极光、扫光、环三层全部静止（雨本来就会静止）。没有一处用 JS 计时器，全是 CSS keyframes。

## 代价

- **比一张位图更"规整"**：自绘的几何没有照片的随机性，观感偏"仪表"而不是"废墟"。这符合本插件的定位（工作台），但确实不是所有人都想要的那种黑客壁纸。
- **层数多**：七层叠加，低端设备上仍是纯合成（`background-image` + `transform`），实测无掉帧；但如果以后要加模糊，得重新量一次。
- **紫与青占了画面**：磷光档原本是单色绿。现在底部偏紫、右侧偏青——这是"炫彩"的代价，也是 ADR 0011"绿只给语义"的松绑（背景色不再承担语义）。

## 验证

- `test/backdrop-layers.test.ts`（10 项）：七层都在、两屏各挂一档、z-index 例外在、**无远程图片**（只允许 `data:`）、四层不透明度上限、颜色来自三个变量、调色板固定为绿-青-紫、reduced-motion 覆盖三层、每个 `animation` 都有对应的 `@keyframes`。
- 真机像素测量（`zlib` 解 PNG + 采样正文区域，先把文字抹透明只留背景）：
  - 中位背景 `rgb(24,41,33)` → 对比度 **11.88:1**
  - 最亮 2% 背景 `rgb(23,55,42)` → 对比度 **10.13:1**
  - 均高于 WCAG AAA 的 7:1，说明"炫彩"没有吃掉可读性。
- 真浏览器截图（`.tmp/backdrop-shots/look.png`）：极光在左上 / 右中 / 底部三处可见，网格与地平线可辨，正文与输入框清晰。
