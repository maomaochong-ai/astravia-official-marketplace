# 0020 — 侧栏「麻花小说网」复刻番茄书库页，并给每本书一张默认封面

- 状态：已接受（2026-10-29）
- 相关：ADR 0006（只用宿主语义令牌）、ADR 0013（书架/阅读页三层）、ADR 0016（空架与字号）

## 背景

ADR 0013 复刻的是番茄**书架**（`/bookshelf`）：封面网格 + 最近更新行表。
用户这轮点名的是**书库**（`/library`）——同一产品里另一个页面，形态完全不同：

- 书架是竖版封面网格，一格一本书，信息只有「书名 + 进度」；
- 书库是横版长条卡，左侧封面 + 右侧四行文字（书名 / 作者·状态·字数 / 简介 / 更新时间），顶部有筛选与排序。

插件当前只有书架这一种形态，作品多了以后没有「按状态、按篇幅、按题材过一遍」的入口。
另外所有书共用同一张排版型封面（首字 + 阶段 + 进度条），列表里看起来像同一本书的多个副本。

## 决策

### 1. 新增第四层「书库」surface

`use-library-route.ts` 的 `LibrarySurface` 增加 `"library"`，书架页顶部加一行页内切换
（`书架 | 书库`），书库页左上角回书架。路由仍然是会话内的状态，不写宿主路由、不写存储（沿用 ADR 0013 §2.1 的理由）。

### 2. 字段映射（不硬造数据）

| 番茄 | 本插件 | 说明 |
| --- | --- | --- |
| 读者（全部/男生/女生） | **不做** | 我们没有性别向数据，造一个就是假的 |
| 分类（全部/主题/角色/情节） | 题材：`全部` + 书库里出现过的 `genre`（上限 6 个，多余的折进「其他」） | `genre` 是建书时填的自由文本 |
| 状态（全部/已完结/连载中） | 状态：`全部 / 进行中 / 已完成` | 由 `phase` 归并：`briefing`、`planning`、`drafting`、`arc_close` → 进行中；`completed` → 已完成 |
| 字数（30 万以下 … 200 万以上） | 篇幅：`全部 / 1 万以下 / 1–5 万 / 5–20 万 / 20 万以上` | 用**已提交章的字数合计**，不是目标字数。番茄的 30 万档对本书库没意义（多数书目标 20–120 章） |
| 排序：最热/最新/字数 | 排序：`最近更新 / 章节数 / 书名` | 没有阅读量，所以没有「最热」 |
| 每页 18 张 | 每页 9 张（3×3） | 面板宽度远小于 1160px；9 张在宽面板正好三行 |

字数合计需要索引里有它：`BookIndexEntry` 增 `words?: number`（`save()` 时按 `chapters[].words` 求和写入）。
旧索引没有这个字段时按 `0` 处理，不猜、不迁移——`0` 落进「1 万以下」是可见的、可解释的偏差。
`books/index.json` 的结构版本不变：新增可选字段，旧读取方忽略它。

### 3. 卡片排版按比例缩放，不照抄像素

面板宽度只有番茄内容区的 1/3 左右，直接搬 328×130 会挤成两行字。取同样的**比例关系**：

> 本节的具体做法（有边框卡片、72×94 封面）已由 **ADR 0024 §4** 取代：卡片改为无边框自由长条，
> 封面 100×130。保留原文作为当时的决策记录。

- 封面 `w-[72px] h-[94px]`（≈10:13），`rounded`，`shrink-0`；
- 右侧单列：书名（`text-sm font-medium`，单行截断）→ 元信息行（`text-xs text-muted-foreground`：题材 · 阶段 · N 章）→
  简介（`text-xs text-muted-foreground`，**3 行 clamp**，取 `premise`）→ 页脚（`text-xs`，更新日期 + 进度条）；
- 卡片本身 `rounded-lg border border-border/60 p-2.5`，hover 用 `bg-muted/40`；
- 栅格：窄 1 列 / `md` 2 列 / `lg` 3 列，间距 `gap-2.5`（与书架实测的 10px 一致）。

### 4. 默认封面

每本书都有一张确定的默认封面，不是占位符：

> 本节的具体做法已由 **ADR 0024 §5** 取代：默认封面改成 6 张 Cleveland Museum of Art 的 CC0 水墨底版
> （base64 内联、240×312、先灰度再 multiply 到 `accent`），不再用 SVG 母题；
> `coverVariant()` 的输出也从 `motif/layer` 变成 `plate/layer`。保留原文作为当时的决策记录。

- `DefaultCover.tsx` 内联 SVG（**不引入位图、不发网络请求、不用 `#hex`**），
  底色 `currentColor` 的 6% 叠层、主字用 `currentColor`、三种几何母题（横纹 / 圆点 / 弧线）；
- 母题与叠层深浅由 `book.id` 的稳定哈希选出（`coverVariant(id)`，纯函数、可测），
  所以同一本书每次看到的封面一样、不同的书看起来不一样；
- 书名首字用 `coverMark(title)`（已有函数），字号按封面档位给两档；
- 封面底部保留 ADR 0013 的细进度条，但**去掉**「阶段」小字：书库卡片右边已经写了阶段，重复标注是噪音。

`BookCover` 保留（书页的 `headline` 大封面继续用它的排版型样式），只在 `grid` 之外新增 `list` 档位，
两处共用 `DefaultCover` 的图形，避免「书架和书库的封面长得不一样」。

### 5. 不做

- 搜索框（宿主的对话就是搜索入口；面板里再放一个输入框会与「视图内无输入框」的约束打架，
  ADR 0011 §2.4 已定这一条）；
- 顶部 6 个导航锚点、站点 logo、「作家助手 / 帮助中心」、页脚；
- 番茄的「因版权问题不支持浏览器阅读」提示：那是版权策略，与本地作品库无关。

## 后果

- 书库页的筛选/排序/分页都是纯函数（`library-model.ts`），可直接单测：分桶边界、`genre` 去重上限、
  页码夹紧、空结果文案。
- `bookshelf-model.ts` 保持不变；新增 `library-model.ts` 只放这一页的计算，不把两页的规则混在一处。
- 卡片里出现「N 章 / 字数」两个数字，均由索引字段算出，不读章节正文——打开书库不发 N 次读文件。
