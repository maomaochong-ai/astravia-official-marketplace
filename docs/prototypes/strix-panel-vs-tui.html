对照要点
1. 工具行：上游 → Using tool exec_command + 参数 + 状态；插件 ▶ exec + 参数 + 状态 —— 同一套 字形语义，插件把 exec_command 收敛成 exec，并补上 exit code 与耗时（上游没有）。
2. 家族字形：◇ patch、◇ view image、⚑ finding、▤ coverage、 ✎ note、☰ plan、⇄ mcp —— 取自上游 internal/render/*。
3. 上游用 ▍ 竖条标用户消息；插件不画用户消息（ADR 0007：文字归对话），只留「第 N 轮」分隔行。
4. 上游状态行是 6 方块扫光 + esc stop / ctrl-q quit；插件换成一条状态带（目标/模式/环境/步数/停止）， 因为面板可点，不需要键盘提示占位。
5. 上游侧栏是单一展开的五个盒子；插件侧栏常驻六块（多出「计划/覆盖/笔记」台账，上游把这三样画在轨迹里）。
