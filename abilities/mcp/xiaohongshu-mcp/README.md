# Xiaohongshu

Official Xiaohongshu automation MCP server from [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp).

Install this Ability in Astravia to run the upstream HTTP release service through Astravia's managed loopback HTTP runtime. Astravia obtains the QR code from the upstream login endpoint and uses the upstream login status endpoint as the only authentication source of truth.
