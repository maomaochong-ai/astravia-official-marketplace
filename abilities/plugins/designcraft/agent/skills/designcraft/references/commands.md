# 命令索引（designcraft）

这张表是这个插件自己的命令索引：每一条都是编辑器里真实存在的功能，`path` 一列直接就是
`designcraft_menu` 的参数，`快捷键` 一列填进它的 `shortcut`。

先查表决定「用哪个功能」，再决定要不要碰坐标。表里没有的，多半是这一版没有，也可能是它只在面板上——以界面为准。
