# 禁用词与自检清单

两件事合在一篇：**写出之后不能有的东西**，和**交章之前必须过一遍的检查**。

## 一、禁用词（写作时就不该出手）

分四类，按「为什么禁」记，不按词表背：

| 类别 | 例子 | 为什么禁 |
| --- | --- | --- |
| 情绪代称 | 心中一凛、眼眶一热、五味杂陈、不由得 | 用生理反应代替具体动作，读者接收不到 |
| 万能副词 | 忽然、突然、莫名、竟然、仿佛 | 它们不提供信息，只提供作者的惊讶 |
| 定型比喻 | 如遭雷击、血液凝固、时间静止 | 读者已经读过一千次，等于没写 |
| 空转形容 | 难以言喻、无法形容、说不出的 | 作者承认自己没写出来 |

替换方法只有一条：**换成可观察的动作或物件**。

- ❌ 他心中一凛。
- ✅ 他把已经签好的名字又描了一遍。

`mahua_set_user_rules` 里的 `bannedWords` 就是这张表的可执行版本：用户自己加的禁用词会进
`book.userRules`，`mahua_check_rules` 逐章匹配并给出位置。**这类词出现在对话里也算违规**——
口语里没人说「五味杂陈」。

## 二、交章自检（按顺序，一次过完）

1. **视角**：本章只有一个观察者。检查有没有「与此同时，在城的另一头……」——那是视角跳跃。
2. **展示**：所有评价性句子，能不能换成一个动作？能换就换。
3. **场景数**：2–4 个。少于 2 是信息段落，多于 5 是流水账。
4. **场景目的**：每个场景结束后，问「谁的处境变了」。没变就删。
5. **对话**：每段对话要么推进信息，要么改变关系。两者都不做的删掉。
6. **重复**：同一段里同一个词最多两次；同一章里同一个意象最多两次。
7. **钩子**：最后一段有没有让人想翻页？没有就删掉最后一段，往往更好。
8. **字数**：目标 ±10%（`mahua_check_rules` 会给出实际区间）。
9. **事实**：`mahua_check_consistency` 无 `error` 级 finding。
10. **伏笔**：本章埋的已用 `mahua_flag_thread` 记账；`mahua_check_threads` 无 `thread.overdue`。

## 三、五种常见崩坏与最小修复

| 症状 | 最小修复 |
| --- | --- |
| 字数不够开始灌景 | 加一个场景（换约束条件），不要加形容词 |
| 人物说话都一样 | 给每个人一个「句尾习惯」与一个「回避话题」 |
| 推进太慢 | 每 3000 字必须有一次不可逆的进展 |
| 结尾平淡 | 删掉最后一段，停在动作或对话中断处 |
| 信息倾倒 | 把设定拆成三次，分别藏在冲突里 |

## 四、不要做的自检

- 不逐句润色：一章改三轮以上，语感会变僵。
- 不为「更文学」而加长句子：长句是节奏手段，不是质量标志。
- 不在评审里给自己打满分：`mahua_save_review` 的七维评分要有原文举证，没有举证的维度按不合格算。
