# 伏笔

伏笔是长篇最容易被「记得住但收不回」的东西。这一篇讲**怎么埋、怎么分级、怎么收、怎么记账**，
记账的动作由 `mahua_flag_thread` 与 `mahua_check_threads` 承担。

## 一、三层伏笔

| 层 | 出现次数 | 回收效果 | 适用 |
| --- | --- | --- | --- |
| 浅（`light`） | 1 次 | 「原来如此」 | 场景道具、次要线索 |
| 中（`medium`） | 2–3 次，每次有表面理由 | 「我就知道」 | 人物命运、重要物件 |
| 重（`heavy`） | 3 次以上，藏在日常细节里 | 全书最大情感冲击 | 核心反转、真相揭示 |

三层不是命名差异，是**读者的记忆负荷**：浅层出现一次就够，重层必须反复但每次都不能引起怀疑。

## 二、埋的四条规矩

1. **有表面理由**：第一次出现时，它在场景里必须有一个当下的用途。
   怀表先用来「看时间」，后面才用来「认父」——顺序反了就是提示。
2. **不解释**：不给特写镜头、不写「他不知道这将改变一切」。
3. **间隔**：同一伏笔两次出现之间至少隔 5 章，否则读者会记住。
4. **不超过三条在跑**：同时推进的 open 伏笔超过 3 条，读者会开始丢线索。看
   `mahua_check_threads` 返回的 `unresolvedRate` 与 `open` 数量。

## 三、收的三种方式

- **兑现**：伏笔的东西按读者预期出现，但代价更高。
- **反转**：伏笔的东西换了含义（怀表里不是照片，是钥匙）。
- **落空**：伏笔被明确放弃并给出理由——只在次要线索上用，核心伏笔落空会让读者觉得被骗。

收的时候必须**回指**：让读者能在同一段里想起它最初出现的样子。

## 四、记账（必须做，别靠记性）

埋下的当下立刻记：

```
mahua_flag_thread {
  content: "父亲留下的怀表从未走针",
  plantedIn: 3,
  dueIn: 18,
  weight: "heavy"
}
```

- `dueIn` 是**承诺**：不要写「以后再说」，写一个具体章号。写不出来说明这个伏笔还没想清。
- 收的时候：`mahua_close_thread`（同一本台账，把 `status` 置 `closed` 并写 `closedIn`）。
- 每章开始前看 `mahua_context` 的 `openThreads`：它按 `dueIn` 升序，最上面的就是**这章该处理**的。

## 五、体检

`mahua_check_threads` 的五个 code：

| code | 含义 | 处置 |
| --- | --- | --- |
| `thread.plantedInFuture` | 记账的埋点章号还没写到 | 改 `plantedIn`，或等写到那章再记 |
| `thread.dueBeforePlanted` | 到期章号早于埋点 | 这两个数有一个错了 |
| `thread.overdue` | 过了 `dueIn` 还没收 | 本章或下章必须处理：收、或改 `dueIn` 并说明理由 |
| `thread.closedWithoutChapter` | 标了已收但没有回收章 | 补 `closedIn`，或改回 open |
| `thread.duplicateContent` | 两笔台账写的是同一件事 | 合并成一笔 |

**未回收率**（`unresolvedRate`）超过 0.4 时不建议继续往前写：先把到期的收掉，
否则后续章节的「悬念密度」会饱和，读者对任何新悬念都不再有反应。

## 六、与评审的关系

`mahua_save_review` 的 `continuity` 维度要举证伏笔状态：本章该收的收了没有、本章新埋的记了没有。
`hook` 维度评的是章末钩子，与伏笔不同——钩子可以是一次情绪中断，不必是一条线索。
