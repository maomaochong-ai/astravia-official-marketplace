# 存稿后八遍改

`mahua_check_rules` 的 `style.*` 是一张工作单，其中的 `blocking` 是**提交门禁**：不清掉它，
`mahua_commit_chapter` 会拒绝这一章。这一页是按工作单改的顺序，每一遍只做一件事：
先删，再换，再调结构，最后才处理跨章。反着做会越改越僵。

> 一遍一章。改完一遍重跑 `mahua_check_rules`，只处理这一遍对应的 code，其余留着——
> 一次改所有问题，等于一次把节奏、语气、结构全打散。

## 第一遍：删（清 `style.stockPhrase` 与 `style.explainTail`）

先做减法，因为删掉的句子不需要再修。

- 删掉每一句"他知道 / 她明白 / 这意味着 / 换句话说"：后文的具体事实已经说明它了。
- 套句（`style.stockPhrase` 列出的那些）连整句删。如果删完段落塌了，说明这句是承重墙，进第二遍处理。
- 删完先别看别的：这一遍的产物应该比原文短 5–15%。

## 第二遍：换（把套句换成观察）

对第一遍删不掉的套句，逐句换成**一个动作或一个物件**。

- 「他不由得停下」→「他把手从门把上拿开」
- 「仿佛被雷击中」→「他退了一步，后腰撞在桌沿上」
- 「一丝疲惫」→「她把眼镜摘下来，用袖口擦了两下才戴回去」

判断标准只有一条：读者能不能看见东西。

## 第三遍：拆合并（清 `style.rhythmUniform` / `style.rhythmNarrow`）

把连续三个同长度的句子打断：

- **拆**：把一句 30 字的句子在动作处切成两句，其中一句只剩主谓。
- **并**：把三句 8 字的短句并成一句长句，用逗号串起细节。
- 一章里至少要有 3 处"一句独立成段"的短句（≤10 字），和 2 处 45 字以上的长句。
- 不要靠加形容词变长：长句靠**并列的动作与细节**，不是靠修饰。

## 第四遍：改段落形状（清 `style.paragraphUniform` / `style.punchlineParagraphs`）

- 把至少两段改成两句段，把至少一段改成五句以上。
- 至少一段**不刹车**：让它结束在一个普通长度的句子上，而不是永远在短句上斩断。
- 段落的第一句不要都用同一个语法起手（"他…""她…""这时…"）。

## 第五遍：换起手与收尾（`style.timeOpening` / `style.punchlineEnding`）

这两条是 `info`：单章不算错，连着两章才算。

- 起手：不用时间、天气、醒来。从上一次动作的**中间**开始，或从一句对话的第三句开始。
- 收尾：停在动作、未说完的话、场景余像上。删掉"原来…""她终于明白…"这类总结句。
- 与上一章对照：同一形式（时间起手 / 短句收尾 / 疑问收尾）**不要连着用两章**。

## 第六遍：拆套式（`style.parallelTriplet` / `style.emotionLabel`）

- **三连排比**（`style.parallelTriplet`）：一组三句只留最有力的一句，其余改成具体动作。
  偶发一次是修辞，两次以上是模板——一章里最多允许一组。
- **情绪贴标签**（`style.emotionLabel`）：强度词 + 情绪名（非常愤怒、感到委屈、有些失落）。
  每条换成一个身体反应加一个选择：他把杯子放回原处，又拿起来；她本来要走，最后留下来洗碗。
  不能全删成动作——人会知道自己愤怒。留 0–1 处，其余落到动作上。

## 第七遍：拆对白（`style.uniformDialogue` / `style.sermon` / `style.expositionDump`）

- **千人一腔**（`style.uniformDialogue`）：对白句长几乎一样。给三个人各改一处——
  一个只会说四个字，一个句子长且带从句，一个总答非所问。
- **说教**（`style.sermon`）：一句对白里出现两个以上「你应该/你必须/做人」。删掉说教句，
  让说话的人提出一个**具体的要求**（把杯子给我），而不是一条道理。
- **信息倾倒**（`style.expositionDump`）：连续四句设定说明。拆成三处，分别藏进一次冲突、
  一次误会、一个人的反对里；每处只交代一半。

## 第八遍：换跨章形式（`style.repeatOpening` / `style.repeatClosing`）

这两条只有在与**上一章**同形时才报，所以改的时候要对着上一章看：

- 开篇形式（`dialogue` / `time` / `action` / `question` / `statement`）换一种。
  上一章从时间起手，这一章从一句对话的第三句开始，或从一个正在进行的动作中间开始。
- 收尾形式（`dialogue` / `action` / `question` / `summary` / `echo`）换一种。
  上一章用「原来……」点题，这一章停在动作或未说完的话上。
- `forms` 字段就是本章的形式读数；连着两章一样，改后一章，不要改已提交的那一章。

## 读出声（人耳，不靠工具）

把改完的章从头读一遍，只标记三种地方：读起来打结、想跳过、想笑。

- 打结 → 句子太长或从句套从句（回第三遍）。
- 想跳过 → 那一段没有事件（删或换成动作）。
- 想笑 → 套句或用力过猛的比喻还在（回第二遍）。

到这一步 `style.*` 应该清零；仍有 `info` 项时，要能说出它为什么可以留——说不出来就改掉。

## 不要做的

- 不逐句润色到第三轮：一章改三轮以上，语感会变僵。
- 不为"更文学"而加长句子：长句是节奏手段，不是质量标志。
- 不在改完之后又加回套句（"这样更有味道"）：味道来自具体，不来自熟悉的词。
- 不在这一层讨论人物与结构：那属于评审，不属改稿。
- 不为了让章节过关而调 `styleBlocking`：门禁是书的决定，不是这一章的。
