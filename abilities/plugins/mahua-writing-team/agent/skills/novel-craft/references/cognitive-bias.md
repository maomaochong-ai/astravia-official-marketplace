# 人物认知偏差包

AI 写小说最大的通病：所有角色用同一套声音说话。根源不是文笔，是**没有给每个角色一套独立的知觉与偏见**。
这一篇讲怎么用「偏差包」把人物分开。

## 一、偏差包的五个槽位

每个主要角色填五项，写在角色档案里（`mahua_save_foundation` 的 `cast` 只存名字，档案本身写在
`mahua_plan_chapter` 之前的构思里，随章纲一起进 `decisions/`）：

| 槽位 | 作用 | 例子 |
| --- | --- | --- |
| 感官映射 | 同一个情绪，这个人用什么感官接收 | 把「孤独」记成樟木与灰尘的气味 |
| 决策偏好 | 面对不确定时先假设什么 | 总先假设最坏，再被证据推翻 |
| 语言习惯 | 句尾、口头禅、回避的话题 | 用反问代替肯定；从不提母亲 |
| 盲区 | 他看不见自己身上的什么 | 认为自己在保护别人，其实在控制 |
| 触发点 | 什么事会让他失去分寸 | 有人当他的面提「欠」这个字 |

五项里至少两项要在一章内被读者看见。看不见的偏差包等于没写。

## 二、感官映射的写法

不要写「他很孤独」，写「他闻到了樟木味，然后才意识到自己在数窗格」。

写法三步：

1. 选一个**具体的早年场景**（被锁阁楼、医院走廊、雨天的车站）；
2. 选一个**当时在场的感官细节**（气味、温度、声音、光线角度）；
3. 之后每次这个情绪出现，**只写细节，不写情绪名**。

第三步是关键：一旦写出「孤独」这个词，前两步就白做了。

## 三、决策偏好的用法

它决定人物在**两难时的默认选项**，而不是性格标签。

- 「先假设最坏」的人，在收到一封没有署名的信时会先想是谁要害他，而不是先想是谁想他。
- 同一个场景里，两个角色对同一件事的**第一个反应**必须不同。这就是偏差包在验收上的判据。

## 四、语言习惯的落地

给每个角色定两件事：

- **句尾习惯**：句尾上扬 / 句尾省略 / 句尾反问 / 从不用句号结尾的短句。
- **回避话题**：一个他永远不会主动提的名词。被问到时的反应（转移、沉默、发怒）也要预先定。

检查方法：把一章的对话**去掉说话人标签**，还分得出谁在说话吗？分不出说明偏差包没生效。

## 五、盲区与触发点

- 盲区让角色在关键时刻做出**读者看得见、他自己看不见**的错误选择。这是共情的来源。
- 触发点让角色在压力下**破功**：平时冷静的人突然提高声音，比任何心理描写都有力。
- 两者要成对使用：触发点被踩到 → 盲区暴露 → 代价发生。这就是一个完整的人物场景。

## 六、和七维评审的关系

`mahua_save_review` 的 `character` 维度评的就是这一篇：角色行为是否有内在一致性与可辨识度。
举证要求：引用一段对话 + 指出它只能出自这个角色。
