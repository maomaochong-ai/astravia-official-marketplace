## 仍存在的布局问题（按严重度，未改）

1. **dock 与结果横条争同一条视觉带。** 结果横条 `absolute inset-x-0 bottom-16`，dock `bottom-3`。
   两者都是浮层、z 值相近（20 与 40），面板高度 < 520px 时中间只剩 4px，读起来是一片。
   建议：横条改 `bottom-[max(4rem,calc(100%-18rem))]`，或用容器查询在矮面板下折叠成计数徽标。
2. **标题芯片与右上动作轨在 360px 互相挤压。** 标题 `max-w-[calc(100%-5.5rem)]`，动作轨是 3×`size-7` + gap ≈ 84px。
   长品牌名先被压到 0 再溢出，而不是先截断文本——应为标题补 `min-w-0` 与 `shrink`，让 `truncate` 生效。
3. **inspector 覆盖 stage 时没有遮挡暗示。** 打开设计栏后左侧画布仍可点击落图钉，但被覆盖部分
   视觉与交互边界不一致；参考实现给被覆盖区加 `pointer-events-none` + 轻微压暗。
4. **备注空态整体消失。** `NotesList` 在清单为空时 `return null`，dock 角标归零也没有反馈；
   `notes.emptyHint` 的文案只在页签里出现一次。建议空态保留一行「点画布留备注」。
5. **导出对话框的格式按钮与主按钮争层级。** SVG / 三个 PNG 尺寸 / WebP 挤在 `flex-wrap gap-1.5`，
   在 20rem 宽下换两行，与 footer 的「保存套件」并列时主次不清。
6. **图钉描边与深色画板耦合。** `ring-white/70` 在 `#121210` 画板上几乎不可见；
   应按画板明暗切换 `ring-black/40`。
7. **触屏无提示。** 动作轨、卡片动作、历史行只有 `title`；键盘有 `FOCUS_RING`，触屏没有等价提示。

## 视觉决策记录（不是问题，避免被"顺手改掉"）

- **画板用 `bg-white` / `#121210`**：logo 必须在可知表面上预览。画板属于内容，不属于 chrome，
  因此不跟随深色主题——跟随了会让用户在深色界面里判断错标志的浅色版本。
- **dock 槽位 `rounded-[22%]`**：与宿主 `ControlBar.tsx:304` 一致；改则与内置设计插件不同形。
- **dock 不加 `backdrop-blur`**：背后画布每帧重绘，模糊要逐帧重读像素。
- **最小字号 9px**：仅用于徽标数字，再小不可读；正文最低 10px。
