# 引擎还是图像服务：先选产线

选错产线的代价不是「图不好看」，而是**交付物不能用**：印刷厂要矢量，海报要质感，
一个是 SVG，一个是 PNG。所以先按这张表判，再看图。

## 判据

| 问题 | 是 → 引擎（矢量） | 否 → 图像服务（PNG） |
| --- | --- | --- |
| 要印刷、要放大到门头/包装、要被别的代码复用？ | ✅ | |
| 要改配色、改字号、改结构后重新导出？ | ✅ | |
| 主体是抽象几何 / 字母组合 / 徽章 / 简笔标志？ | ✅ | |
| 要写实材质（绒毛、金属、布料）、要角色摆姿势、要插画质感？ | | ✅ |
| 用户明确说「要照片感 / 要 3D 渲染图 / 要手绘插画」？ | | ✅ |

两边都不是：先问一句。**不要**用引擎硬画一只猫去充当「可爱吉祥物」，也不用图像模型画一个
需要在名片上放大的字母组合。

## 宿主是否已经配好图像服务

面板启动时会探测。三种结果，处理方式不同：

- **可用** → 面板自动切到图像产线并选第一个 provider。用户可以手动切回矢量，切过就不再被覆盖。
- **无 provider** → 停在矢量，面板不提示「去配置」，因为不是每个人都需要。
- **权限被拒**（`media.generate` 未授予）→ 说明去「设置 → 能力 → 插件」重新授权；
  升级不会自动带新权限。

## 两条产线的产物差异

| | 引擎 | 图像服务 |
| --- | --- | --- |
| 文件 | `<slug>.logocreator-design/variants/N.svg` + `design.astravia-log` | 宿主 blob（PNG），记录里只有 blobId |
| 可重建 | 参数 + seed 相同 → 字节相同 | 不能重建，只能重生成 |
| 可编辑 | 改字段即改图 | 只能图生图微调 |
| 计费 | 无 | 每张一次调用，走用户自己的额度 |

## 交付话术

- 引擎：给 SVG + `design.astravia-log`，告诉他改哪个字段会变什么。
- 图像服务：**先说明**这是 PNG、不能放大、不能出品牌套件；再给图。
  用户如果要印刷件，回到引擎重出一版矢量，而不是把 PNG 塞进印刷稿。
