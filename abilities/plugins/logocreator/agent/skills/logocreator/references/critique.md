# 审图：说"做好了"之前跑一遍

读这一页的时机：`logocreator_design` 返回之后、交付之前。

这一页是**流程**。每种失败为什么会发生，在 `anti-patterns.md`；这里只回答"按什么顺序看、
看哪一项、看完能下什么结论"。十项里任何一项答不上来，就不要把它写进交付说明。

## 0. 先确认看的是同一份东西

- `files[]` 的路径真实存在：`fs.read` 读前 200 字节，确认以 `<svg` 开头。
- `subject` 与你想要的题材一致。不一致 → 回去改 `intent`（`subject-atlas.md`）并重跑，
  **后面九项都不用做**，因为你审的不是同一个标志。
- 记住 `seed`。它是交付的一部分。

## 1. 眯眼测试：只剩一个焦点

缩到 128px 宽看一眼：还剩几个视觉元素？

- 图形 + 外环 + 副标题 + 装饰线 = 四个焦点，是噪声。
- 只剩一个 → 过。剩两个 → `detail` 降一档，或换没有装饰的风格（`minimal` 无环无射线）。

## 2. 24px 存活

屏幕最小 24px 高、印刷最小 10mm。把 `markSvg` 导到 24px 看。

- 最危险的是 `luxury`（笔画 4）和 `3d`（挤出 9）：前者化成灰线，后者挤成一团。
- 失效的正确修法不是加粗笔画，而是换 `minimal`，或者改 `icon` 只留图形。
- 结论写成"24px 下可辨 / 已糊"，不要写"小尺寸也没问题"。

## 3. 单色存活

传 `monochrome: true` 再看一次。渐变退成单色、挤出退成深叠深。

- 单色下失效 → **换风格重做一版**，不要把彩色版转灰度交付（引擎没有灰度副本）。

## 4. 对比度：只算引擎排的版

引擎保证 `ink` 对 `surface` ≥ 8:1、`muted` ≥ 4.2:1（具体口径见 `colour.md`）。

- 这两个数**只覆盖引擎自己合成的文字与背景**。
- 把标志贴到别处时，用返回的 `palette` 重算：`contrastRatio(palette.ink, 目标背景)`。
  低于 4.5 就换 `on-dark` / `on-light` 变体，不要自己调色。
- 不要写"符合无障碍标准"这种整句结论；写"ink #15130F 对 #FFFFFF = 17.4:1"。

## 5. 字标排得下

- 引擎按字符数估宽度并**缩小**字号，不裁切。所以超长名称不会溢出，会缩到看不清。
- 检查：字标宽度是否已占画布约 80%（引擎上限）。是 → 已到极限。
- > 18 字符且 24px 不可读 → 换 `icon`，名字交给版面。

## 6. 徽章弧线

`emblem` 的名称排在圆周上，**超过 26 字符会被截断**（不是缩小）。

- 检查 `svg` 里 `textPath` 的文本与品牌名逐字一致。少了两个字，就是截断。
- 名称长 → 换 `icon-name`，或先把名字缩短。

## 7. 中文与字族

- 中文名的字母组合是**单个汉字**，这是设计，不是失败（`cjk-brand-mark.md`）。
- 字标是文本节点，不嵌字体：换机器会用系统字体。需要像素一致时，交付里写明"需转曲"。

## 8. 干净度（一条命令）

```powershell
Select-String -Path <file.svg> -Pattern "NaN|undefined|<image|@import|https?://(?!www\.w3\.org)"
```

应无输出。品牌名里的 `<`/`&` 必须已转义成 `&lt;`/`&amp;`。

## 9. 三个变体是同一个品牌

同一批的 `palette.primary` 应接近（同 `auto` 推导）、`subject` 应相同或同族。

- 三个色调完全不同 → 每次 `intent` 都改了措辞，那是三次重开，不是三个方案。
- 想给"三个方向"，就把三种 `style` 或三种 `type` 说清楚，而不是偷偷换题材。

## 10. 交付说明（三行 + 一句下一步）

```
文件：logos/paperline/paperline-1.svg（seed 11）
图形：book · icon-name · luxury
主色 #2F6FF5 · 纸色 #FFFFFF · 辅助 #6E7CF2
下一步：要整套品牌套件 / 换一版更轻的风格 / 要中文版
```

不要写"现代、简洁、有力量"——那是形容词，不是结论。
