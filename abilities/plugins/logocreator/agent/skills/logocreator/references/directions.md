# 定方向：一句话怎么变成四个参数

读这一页的时机：拿到 brief 之后、调 `logocreator_design` 之前。

这一页只管**顺序与提问**；四个参数各自的取舍在 `structure.md` / `style-fit.md` / `colour.md` /
`subject-atlas.md` 里，别在这里找重复的表。

## 先把 brief 拆成四栏

拿到用户的话，按这四栏填空。空着的格就是你要问的。

| 栏位 | 问的是 | 例：`"我在山上开了家茶馆，想走安静一点的路线"` |
| --- | --- | --- |
| 生意 | 卖什么、给谁 | 茶馆 · 登山客与本地熟客 |
| 气质 | 三个形容词，取最强的那个 | 安静 · 山野 · 手作 |
| 题材 | 有没有一个具象物可以画 | 茶叶 / 山 / 杯 |
| 场景 | 最先用在哪 | 门头 + 杯贴（印刷） |

**只问缺的那格。** 全空就问两句："它做什么生意？最先用在哪？"
已经说了气质就别再问"想要什么风格"——那是你要替他判断的部分。

一次问完。边做边问是另一种形式的返工。

## 四个决定的顺序（顺序不能换）

```
1. intent   → 画什么        （题材词决定图形，也决定 auto 的色相锚点）
2. type     → 什么结构      （由"最先用在哪"反推）
3. style    → 什么语气      （由行业性质决定，不由偏好决定）
4. colour   → 什么颜色      （默认 auto；有品牌色才覆盖）
```

为什么这个顺序：`intent` 同时决定图形**和**颜色锚点（`SUBJECT_HUES`），
先定它，后面三步才有依据。反过来说——先挑了颜色再想画什么，用户拿到的就是"配了色的几何体"。

## 每一步的一句话依据

交付时你只需要为每个决定准备一句话，例如：

- `intent`：**"用户说'茶叶'，所以取 leaf 而不是 mountain——山是他所在的地方，不是他卖的东西。"**
- `type`：**"门头、杯贴、名片都要用，所以 icon-name；只有 app 图标时才会选 icon。"**
- `style`：**"茶馆的对手都在用书法体，这里用 luxury 的细笔画 + 宽字距，是另一种'安静'。"**
- `colour`：**"auto 给了暖绿——leaf 的锚点在 142°，符合茶；没有覆盖它。"**

凑不出这一句，说明这一步其实没做决定，只是点了默认值。

## 一个完整的例子

> "帮我的独立书店做个标志，叫 Paperline，在老城区，想有点旧书的气质。"

- 生意：独立书店 · 老城区的读书人 → 气质取"旧、纸、克制"
- `intent`: `"an open book mark for an old-town independent bookshop"` → `book`
  （不写 `"vintage literary atmosphere"`：没有名词，会退到 `abstract:*`）
- `type`: `icon-name`（门头 / 书签 / 网站都要用）
- `style`: `luxury`（细笔画 + 宽字距读作"克制"；`retro` 读作"美式复古"，不是这家店的语气）
- `colour`: `auto`（旧书气由 serif 与低饱和承载；硬指定棕色会把书店变成咖啡店）

```json
{
  "brandName": "Paperline",
  "type": "icon-name",
  "style": "luxury",
  "detail": "balanced",
  "intent": "an open book mark for an old-town independent bookshop",
  "count": 3
}
```

## 出几个

`count: 3` 是默认：一个无法比较，八个是让用户做选择题。

唯一需要更多的情况：`style` 拿不准，用 `count: 4` 跑同一套参数看四种风格的差异。
这时 `intent` 越具体，比较越有意义——四个抽象构成之间的差别，用户看不出来。

## 症状 → 病因 → 改哪里

| 症状 | 真正的病因 | 改哪里 |
| --- | --- | --- |
| 出来的东西"很 AI" | `intent` 全是形容词，没有名词 | 换成具体物，见 `subject-atlas.md` |
| 和同行一模一样 | 只给了行业名，没给区别点 | `intent` 里加一句"只有它有"的东西 |
| 看着空 | `detail: minimal` + 抽象题材 | 换具象题材，或 detail 提到 balanced |
| 小尺寸糊成一团 | `luxury` / `3d` + 细笔画 | 换 `minimal`，或按 `critique.md` 验证后重做 |
| 名字放不下 | 名称太长却选了 `icon-name` | 缩到 18 字符内，或改 `icon` 让名字去别处排 |
| 颜色不像这个行业 | 题材词的锚点赢过了行业 | 改 `intent` 的措辞，不要改调色板（`colour.md`） |
