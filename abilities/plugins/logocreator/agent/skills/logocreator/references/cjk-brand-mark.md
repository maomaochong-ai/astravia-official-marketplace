# 中文／日文品牌标志

读这一页的时机：品牌名含中日韩汉字（或假名），或客户面向中文市场。

引擎对 CJK 有三处专门处理，也有两处它**做不到**。判断之前先知道边界在哪，
否则会把"引擎的取舍"当成 bug 去修，或者把"会出问题的地方"直接交付出去。

## 1. 文字标志：一个汉字占一个 em

`advanceEm()`（`compose.ts`）对 `U+2E80` 以上的字符按 **1 em** 计，拉丁小写约 0.52 em。
所以同样字符数，中文名的实际宽度接近英文的两倍。

字号算法：`fontSize = clamp(18, baseSize, 393.2 / 字宽和)`，`icon-name` 的 baseSize 是 60。

| 名称长度 | 实际字号 | 结果 |
| --- | --- | --- |
| 2–6 字 | 60（上限） | 舒展，正常 |
| 7–21 字 | 按比例缩到 18–56 | 仍可读，但小尺寸要验 |
| 22–27 字 | 压到 18 下限 | 24px 下基本不可读 |
| ≥ 28 字 | 仍固定 18，宽度超出画布 | **会跑出画布**，必须换 `icon` |

最后一行是硬边界：引擎**不为中文断行**（`planWordmark` 只在有空格且长度 > 16 时分行），
所以超长中文名不会折成两行，只会横向溢出。28 字以上的名字请直接选 `icon`，
把名字交给版面排版。

## 2. 字母组合：只有一个汉字

`initialsOf()` 在没有拉丁首字母时返回第一个汉字，`glyphBlock()` 对它返回 null，
于是走 `cjkInitialSvg()`：**一个居中的文本节点**（`font-size="62"`，`dominant-baseline="central"`）。

三个后果，交付时必须知道：

- **字形由系统决定。** 它用 `FONT_STACKS.sans`，不是你选的风格字族——`luxury` 的中文单字
  不会是衬线体。需要衬线时，只能交付后人工替换字形。
- **不是描边字。** 拉丁字库是路径（可任意放大、可改色、可做镂空），这个汉字是文本节点。
  导出没问题，但"把汉字转成路径"引擎不做。
- **双语名会丢掉中文。** `"青岚 Tea House"` 的分词是 `青岚 / Tea / House`，
  取前两词首字 → `青` + `T`，再过滤掉非拉丁 → 只剩 **`T`**。想要 `青`，就把品牌名写成纯中文。

## 3. 风格与字距

- `uppercase` 对汉字是空操作（`toUpperCase()` 不改变 CJK），不用担心。
- `luxury` 的字距是 +0.16 em，`retro` 是 +0.04 em。汉字拉开到这个程度读作"疏排"，
  在高端行业是成立的语气；`geometric` 的 +0.02 几乎等于没有。**不要为了"中文更松"去调字距**，
  这是风格的组成，不是中文参数。
- `hand-drawn` 的 `FONT_STACKS.hand` 是拉丁手写栈，中文会回落到系统楷体/宋体——
  中文的"手作感"在引擎里只有笔画抖动与纸纹（`texture: grain`）承载，字形本身不变。

## 4. 题材词：中文描述不参与匹配

`subjectFor()` 只认英文关键词表（`catalog.ts#SUBJECT_KEYWORDS`）。
用户用中文说"我要一片叶子"，`intent` 里必须写成英文：

```json
{ "intent": "a leaf mark for a mountain teahouse" }
```

写 `"山间茶馆的叶子"` 不会命中任何题材，直接退到 `abstract:*`。
这是最容易踩的一脚：**中文用户 + 中文 brief = 必须翻译题材词**，其余字段（名称、标语）保持中文。

## 5. 名称本身就是资产

- 中文品牌名常有既定写法（繁体/简体、异体字），**照抄用户给的写法**，不要规范化成简体。
- 不要为了排版把"青岚茶事"缩成"青岚"——那是改名，不是设计。
- 名称 ≥ 8 字时，先问一句"正式全称是哪个"，商标注册名与日常叫法常常不同。

## 6. 检查清单（中文专属）

- [ ] `intent` 里的题材词是英文，且放在句子最前
- [ ] 名称字数 ≤ 27（否则已换 `icon`）
- [ ] 若是 `monogram`：确认单字是想要的字（双语名会只剩拉丁首字母）
- [ ] 若是 `monogram` + `luxury`：确认用户接受"系统 sans 字形"而不是衬线
- [ ] 交付说明里写了"字标为文本节点，正式印刷前需转曲"
- [ ] 没有把简体/繁体悄悄换掉
