# 上游文档入口

上游 `https://github.com/storytold/cadcraft` 的文档是英文的、按工程口径写的。这里是按任务去找的索引，
不是正文——需要细节时打开链接读原文，不要凭记忆复述上游功能。

| 想弄清什么 | 去哪读 |
| --- | --- |
| 这个应用支持什么系统、怎么安装 | 仓库 `README.md` 的 Getting started 一节 |
| 具体功能怎么用 | 仓库 `docs/` 与 `README.md` 的功能表 |
| 文件格式的兼容边界 | 仓库 `docs/` 里对应的格式说明 |
| 已知问题与限制 | 仓库 `ROADMAP.md` / `CHANGELOG.md` |

## 在 Astravia 里怎么操作

上游文档讲的是桌面应用，不涉及插件面板。问「这里怎么点」时看 `SKILL.md` 里的工具清单与坐标规矩，
不要拿上游的快捷键往面板上套——面板里收到的是按键事件，不是上游的菜单命令。
