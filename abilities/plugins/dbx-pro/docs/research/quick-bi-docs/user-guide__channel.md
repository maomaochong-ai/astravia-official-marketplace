将 Quick BI AIPro 接入钉钉、飞书等 IM 平台后，您可以在 IM 中直接向 AIPro 提问并获取分析结果。绑定 IM 账号后，IM 与 Web 端的会话保持同步。本文介绍如何绑定 IM 账号以及在 IM 中使用 AIPro 的说明。  

## **前提条件**
* **版本购买**：您所在的组织已购买 Quick BI AIPro 版本。

* **权限配置** ：您至少拥有 Quick BI AIPro 的**基础功能**权限。

* **渠道接入** ：管理员已在管理中心完成该 IM 渠道的机器人配置。具体操作说明请参见[频道管理](https://help.aliyun.com/document_detail/3055223.html)。

## 功能入口
在 Quick BI AIPro 左侧的历史记录中，切换至**频道**页签。页签中按渠道展示管理员已配置的机器人。

![历史记录中频道页签下按渠道展示的机器人](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6616628871/p1099036.png)

## 绑定 IM 账号
AIPro 账号与 IM 账号是两套独立的账号体系。需要先完成绑定，机器人才能识别您的身份，并使用您在 AIPro 中的权限、记忆和数据资产。

1. 在**频道**页签中单击目标渠道下的机器人名称。

2. 单击**开始绑定**，页面显示本次的配对码。

   ![开始绑定后显示的一次性配对码与操作提示](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6616628871/p1099037.png)
3. 在对应的 IM 中搜索该机器人名称并发起会话，将配对码发送给机器人。

   配对码为一次性使用，有效期 2 分钟。超时未发送时，返回上一步重新获取。
4. 验证通过后绑定完成，机器人会发送一条欢迎消息，此后即可在 IM 中直接向 AIPro 提问。

**说明**

若您尚未绑定就在 IM 中向机器人发送消息，机器人会提示您先登录 AIPro 网页端，在**频道**页签中完成绑定。

## 会话与记忆
* 每个渠道拥有独立的频道会话列表。同时绑定多个渠道时，各渠道的会话上下文互不影响。

* IM 与 Web 端共享同一 AIPro 账号的长期记忆，包括您的使用偏好、已沉淀的分析思路以及已授权的数据资产。解除绑定或被移出机器人可见范围后，长期记忆不会被删除。

## 双向同步
IM 与 Web 端的**频道**访问同一份会话数据：

* 在 IM 中发送消息后，该消息与 AI 的回答同时出现在 Web 端的**频道**会话中，两端同步展示任务执行状态。

  * IM端：

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6616628871/p1099111.png)
  * Web端：

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6616628871/p1099112.png)
* 在 Web 端**频道**中发送消息后，机器人会在 IM 中同步一条系统消息，提示您在 Web 端继续了该会话。该消息由机器人发出，不会显示为您本人发送。

**说明**

* 两端保持一致的内容包括：会话顺序、提问内容、AI 回答的语义、任务状态、错误与停止状态，以及分析产物指向同一结果。受各 IM 平台的消息能力限制，两端的展示样式不完全相同，IM 中也不呈现可交互的图表。
