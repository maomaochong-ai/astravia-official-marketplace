## 发布日期
2020年06月30日

## 更新内容
* 升级查询控件功能：
  * 展示类型为树形下拉中，支持查询方式选择多选。
  * 查询控件界面新增清空、重置按钮。
  * 展示类型为日期选择中，优化时间粒度定制快捷区间功能。

  详情请参见[新建查询控件](https://help.aliyun.com/document_detail/151455.html#task-2383818)。
* 升级仪表板组件和电子表格中的字段过滤器功能。 详情请参见[日期查询](https://help.aliyun.com/document_detail/151454.html#task-2384032)、[文本查询](https://help.aliyun.com/document_detail/151453.html#task-2384036)、[数值查询](https://help.aliyun.com/document_detail/151452.html#task-2384037)和[字段过滤](https://help.aliyun.com/document_detail/65848.html#concept-bvw-phy-5db)。

* 升级仪表板组件和电子表格的导出功能：
  * 将导出图片和导出PDF合并为导出按钮。
  * 在导出按钮中新增导出Excel功能。
  * 支持导出到OSS服务器上。

  详情请参见[管理仪表板](https://help.aliyun.com/document_detail/65854.html#concept-f4y-cry-5db)和[导出控制](https://help.aliyun.com/document_detail/172232.html#task-2534900)。
* 监控告警和订阅任务新增通知方式。 告警方式和订阅通知均支持以钉钉工作通知和钉钉群方式通知到用户。详情请参见[配置监控告警](https://help.aliyun.com/document_detail/114219.html#task-2423365)和[创建订阅任务](https://help.aliyun.com/document_detail/101302.html#task-2448819)。

* 升级仪表板组件功能：
  * 当查询结果的条数超过10000时，会提示仅显示10000行。
  * 将仪表板编辑页面的预览行数更名为结果展示。
  * 矩阵树图新增显示总计并支持给色块自定义颜色。

    详情请参见[矩形树图](https://help.aliyun.com/document_detail/55690.html#concept-q2y-4gf-vdb)。
  * 将图表样式中配色设置的默认色系更改为主题色。

    涉及的仪表板组件为仪表盘、散点图、气泡图、色彩地图和气泡地图。详情请参见[仪表盘](https://help.aliyun.com/document_detail/55668.html#concept-mmt-3n2-vdb)。
* 升级交叉表的升降指标。升降指标的默认配置支持跟随系统语言切换。  
  当系统语言为中文时，图表显示为红升绿降。 ![china](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2555258951/p112764.png)  
  当系统语言为英文时，图表显示为绿升红降。 ![intl](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2555258951/p112765.png)
* 升级移动端图表组件展示功能。  
  以下功能在PC端配置完成后，支持在移动端显示：
  * 支持图表间的条件级联。
  * 支持筛选时间粒度年月日时分秒。
  * 支持选择快捷区间。
  * 支持图表间的联动、钻取和跳转。  
    **说明** 涉及的仪表板组件为线图，柱形图、堆积柱形图、百分比堆积柱形图，条形图、堆积条形图、百分比堆积条形图，面积图、堆积面积图、百分比堆积面积图。
  * 优化数字标签。
  * 支持展示0轴线。![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3355258951/p129486.png)
  * 支持全屏查看图表组件。

  详情请参见 [查看报表](https://help.aliyun.com/document_detail/65720.html#task-vnp-tyy-5db)。
