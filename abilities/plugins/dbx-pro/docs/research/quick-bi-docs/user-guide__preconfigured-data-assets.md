**预配置数据资产**功能允许管理员将部门内或业务模块下常用的数据资源，预先打包为一个标准化的数据资产包，并投放给目标业务用户，使业务用户在新建分析任务时无需手动配置或搜索数据，即可直接使用已前置筛选、治理验证好的精选数据资产。本文将为您介绍如何预配置并管理数据资产包。  

## **前提条件**
* **版本购买**：您所在的组织已购买Quick BI AIPro版本。

* **权限限制** ：仅同时拥有 AIPro**集中管理** 权限和**企业安全**权限的管理员，可以进入管理中心操作预配置数据资产。仅拥有其中一项时无法操作。具体权限配置说明请参见《用户权限》。

## 功能入口
进入Quick BI AIPro的**管理中心** ，点击顶部导航栏的**预配置数据资产** 。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9571409871/p1100726.png)

## 新建资产包
创建资产包时，可以选择组织内的任意数据资产。若目标用户对其中部分资产没有权限，系统会在创建资产包时自动为其授权，确保目标用户能正常使用资产包内的全部数据。

1. 点击**预配置数据资产** 页面右上角的**新建预配置数据** 按钮。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9571409871/p1101228.png)

3. 单击**创建** 按钮，系统将新增资源包并自动投递给已设置的目标用户，同时为目标用户补齐资产包内数据资产的权限。成功后，业务用户在新建分析任务时，可以在对话框的**常驻数据**中选到该资源包；也可以在输入「@」唤起的数据资产列表中选到该资源包。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0533204871/p1086551.png)

**重要**

* 系统为目标用户补齐权限时，仪表板授予**查看** 权限，数据集、数据表组合、文件和 API 数据授予**使用**权限。授权后目标用户即可查看对应数据，创建前请确认资产包内的数据不存在越权风险。

* 仪表板作为数据资产时，仅使用仪表板中已呈现的数据进行分析。若目标用户需要使用仪表板中没有的维度做深度拆解，请在资产包中同时加入其底层数据集。

* 目标用户包含用户组时，组内新增成员自动获得该资产包；成员被移出用户组后，对应资产包同步移除。
