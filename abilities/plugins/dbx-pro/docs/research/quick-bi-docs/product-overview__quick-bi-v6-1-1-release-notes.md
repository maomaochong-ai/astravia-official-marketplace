## 重点升级概览
* **智能小Q**

  * **售卖规则**：智能小Q Agent能力支持按照实际使用用户数购买（100个用户起可按需增购），无需为全员买单，只需为核心使用者付费，灵活控制AI使用成本。

  * **个人知识库**：新增个人知识库功能。您可以将基于自身业务角色和经验沉淀的个人知识，上传至个人知识库中，并在小Q报告生成和小Q解读时应用，让AI生成的报告更贴合您个人的实际工作需求与视角。

  * **小Q问数**：支持智能选表，当数据集选择规则无法明确命中数据集时，可通过智能判断，由大模型根据问题语义选择合适的数据集。

  * **小Q解读**：支持接入企业知识库，调用企业知识库中的业务逻辑、分析思路以及内容模板。

  * **小Q报告**

    * 当报告内存在多个动态引用的洞察分析或问数结果时，支持在报告编辑页针对单个结果区块进行数据更新操作，且不影响其他结果区块的内容与状态，避免全量刷新带来的内容波动，保护已优化成果。

    * 支持在小Q报告编辑页中，查看某一洞察分析结果的生成提示词，帮助您直观了解当前结果是基于什么问题及需求生成的，便于您快速参考与复用优质指令，或对当前洞察任务的提示词进行进一步优化。

    * 在报告中使用AI助手进行洞察分析或问数时，可查看大模型的思考过程，帮助您追溯和验证数据的分析过程，以验证其合理性。

    * 支持在移动端微应用中搜索及查看报告。

  * **小Q洞察**：小Q洞察重磅升级，更智能、更全面、更灵活，带给您全面焕新的交互体验。

    * 全局视角，层层下钻：从单指标升级为多指标归因树。支持从宏观经营节点逐级下钻至叶子节点，一眼看透数据波动的根源。

    * 双模引擎，即时响应：新增"即时"与"定期"双计算模式，既满足临时探索需求，也支持预计算的高效查询。

    * 权限分级，安全可控：首创"全局模式"与"私有模式"，基于数据集权限灵活管控，让数据共享更安全。

    * 维度拓展，对比更自由：突破时间限制，新增非时间维度对比归因，分析视角更广阔。

* **数据构建**

  * **数据源**

    * StarRocks数据源支持初始化SQL、HINT语句。

    * Clickhouse数据源支持系统内置函数 BI_PERCENTILE。

  * **数据集**

    * 多逻辑表数据集支持加速引擎。

    * 数据集地理字段支持地理数据匹配，保障地图可视化展示及分析结果的准确性。

    * 关系模型多逻辑表支持LOD函数。

    * 关系模型选择度量字段为关联键时，支持将该度量字段转换为维度字段。

    **重要**

    因底层探索空间计算资源存在限制，当使用关系模型对探索空间内数据（上传文件、API数据源、钉钉表格等文件类数据源）进行建模时，仅支持同时查询3个及以下表中的数据，若同时拖入3个以上表中的字段，查询将报错。若您需要同时查询更多表中的数据，建议您使用物理模型进行建模。
* **数据分析**

  * **探索分析**：面向业务用户，提供即时、灵活的探索式分析体验，无需技术背景即可自主挖掘数据价值。

    * 灵活多维探索：打破固定报表的束缚，支持通过拖拽自由组合维度、度量，满足多变的分析诉求。

    * 智能推荐图表：支持表格、柱图、线图、饼图、漏斗图、组合图图表智能推荐与指定切换，快速找到数据的最佳呈现方式。

    * 强大的快捷计算：无需编写复杂公式，内置求和、平均、去重计数等多种聚合方式，一键即可完成同环比、占比、累计计算等快捷计算，帮您快速获得关键业务指标。

    * 深入的分析能力：支持分组对比，轻松比较不同活动周期、不同用户群的数据表现。通过自定义下钻，您可以从宏观数据层层深入，直至问题细节。

    * 便捷的分享与协作：分析结果可以轻松导出，一键分享至钉钉、企业微信、飞书等平台，加速团队协同与决策。

  * **数据展示格式**：数据展示格式配置能力优化。扩展数据集、仪表板、电子表格等业务模块的数据格式配置功能，满足对数据展示的个性化格式需求。

  * **可视化图表**

    * 支持在仪表板中对百分比、占比等比率类数据配置小数位数，满足不同业务下的精度展示需求。

    * 优化轴标签、系列设置、工具提示、辅助线、标注等图表元素的数据格式配置逻辑，打通字段与图表数据格式继承关系。

    * 整体优化数据标签布局和展示内容等配置项，提升数据标签展示效果和可用性。

    * 图例符号支持样式配置：线面图类图表的图例符号可跟随图表线条粗细同比例调整，且可选择展示样式；其他图表的图例符号可跟随图例字体大小同比例缩放。

    * 矩形树图支持多维度拆分能力，可通过配置多个维度字段，实现多层级结构的数据展示。

  * **查询控件**：查询控件树形下拉且多选场景支持携带参数跳转其他图表。

  * **电子表格**：新增AI函数功能，支持在电子表格中直接使用翻译、分类、提取、总结等AI能力，无需复杂公式，即可智能处理文本内容，数据分析效率大幅提升。

* **数据应用**

  * **订阅**

    * 订阅任务触发方式新增URL触发。在该方式下，系统将为订阅任务生成一个专属的webhook地址，IT团队/数据团队拿到该地址后可将其集成至各类外部系统或自动化流程中，通过访问该URL立即触发订阅任务。

    * 订阅任务的数据权限支持选择为"接收人"或"任务负责人"。当选择为接收人时，系统将根据每位接收人的数据权限对其订阅内容进行单独查询并截图推送，使不同接收人能根据自身数据权限看到差异化的内容，实现"千人千面"的推送效果。

    * 支持开启图表数据为空处理。开启后当订阅内容中的图表数据为空系统将拦截推送，并以 30 分钟为间隔进行重试。重试次数视推送周期而定，最多重试4次。若重试后数据仍为空，则订阅任务失败，订阅任务创建者将会收到通知。

* **企业级能力**

  * **用户管理**

    * 支持组织管理员在用户管理页面中帮助用户绑定邮箱\&手机号。

    * 组织管理员可在成员管理页面中管理组织内成员的Agent能力使用席位，确保每位成员仅能使用与其业务角色相匹配的AI能力，提升AI资源分配的合理性和成本的可控性。

* **开放平台**

  * 以下OpenAPI更新：

    * 新增"新增作品的协同授权记录（AddWorksAuthorization）"接口。

    * 支持通过修改数据源配置（UpdateDataSource）接口修改VPC数据源。

**重要**

Quick BI将在V6.1.1版本对所有存量的旧版树图和旧版来源去向图进行批量下线操作。本次升级后历史存量的图表将无法使用并提示报错，且无法恢复。如您有线上业务需要用到类似功能，建议使用指标拆解树和新版来源去向图替代。
