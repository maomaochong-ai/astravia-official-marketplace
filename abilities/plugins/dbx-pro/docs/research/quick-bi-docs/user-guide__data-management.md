在**数据管理**页面中，展示了当前组织内已有的各类型数据资产，包括数据表组合、文件、API 数据。管理员可以在此按需新增数据资产，以让业务用户可在企业的数据广场中挑选使用；也可以维护已有数据资产的相关信息并对其进行管理操作。本文将为您介绍具体操作步骤。  

## **前提条件**
* **版本购买**：您所在的组织已购买Quick BI AIPro版本。

* **权限限制** ：仅**管理员** （即拥有AIPro**集中管理** 权限的用户）可进入管理中心，对数据资产进行新增和管理操作。具体权限配置说明请参见[用户权限](https://help.aliyun.com/document_detail/3045424.html)。

## 功能入口
进入Quick BI AIPro的**管理中心** ，点击页面顶端导航栏的**数据管理**。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7961409871/p1100619.png)

## 新增数据资产
支持在数据管理页面中新增**数据表组合** 、**文件** 、**API数据** ，具体操作如下。 当某一页签下暂无数据时，空态页面会提供对应的新增入口，您可以直接新增数据表组合、上传文件或连接 API 数据。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7961409871/p1100832.png)

### 数据表组合

数据表组合是在未预先创建数据集的情况下，将某一数据源中多个数据表整合而成的数据资产，适用于有较明确的分析主题的场景，例如：将数据源中承载销售信息的数据表进行整合，用于销售数据分析。您可以在**数据表组合**页签下进行新增操作。

1. 点击页面右上角**新建数据表组合** 按钮。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090769.png)

2. 在**创建数据表组合** 弹窗中，输入待添加资产的相关信息。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090772.png)

   <table> <thead> <tr> <td><p><b>配置项</b></p></td> <td><p><b>说明</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>名称</p></td> <td><p>自定义输入当前数据表组合的名称。您可以根据实际业务含义命名，例如：2026年Q2销售数据组合。</p></td> </tr> <tr> <td><p>工作空间</p></td> <td><p>选择数据表组合所属的工作空间。此处的工作空间选项列表中，将仅展示您已加入的工作空间。若您未看到目标工作空间，请确认当前账号是否已加入该空间。</p></td> </tr> <tr> <td><p>数据源</p></td> <td><p>选择数据表组合所属的数据源，系统将据此加载对应的数据表列表。</p></td> </tr> <tr> <td><p>数据表</p></td> <td><p>按需从选定的数据源中选择具体的数据表，作为本次组合的数据基础。</p></td> </tr> <tr> <td><p>添加到</p></td> <td><p>指定当前数据表组合新增后在列表目录中的储存位置。默认为根目录，也可以选择已有文件夹进行归类管理。</p></td> </tr> <tr> <td><p>描述</p></td> <td><p>填写当前数据表组合的描述说明，例如：业务用途、注意事项等内容，帮助业务用户或AI更准确地理解其含义。</p></td> </tr> </tbody> </table>
3. 点击**确定** 按钮即可执行新增操作。系统将自动对当前数据表组合进行学习，建议等系统完成学习后再基于该数据资产发起分析任务等操作。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090774.png)

4. （可选）您可以对已添加的数据表组合进行展示范围设置、编辑、协同授权等管理操作，具体操作说明请参见本文[管理数据资产](#70e3a2aba3hsm)。

### 文件

文件即以本地文件形式上传至Quick BI AIPro的数据资产，适用于需要基于本地文件快速发起分析的场景，例如：对第三方平台中导出的Excel文件发起分析。您可以在**文件**页签下进行新增操作。

1. 点击页面右上角**上传文件** 按钮。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090775.png)

2. 在**上传本地文件** 弹窗中，配置待上传文件的相关信息。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090777.png)

   <table> <thead> <tr> <td><p><b>配置区域</b></p></td> <td><p><b>说明</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>① 添加文件</p></td> <td><p>点击或将需要上传的文件拖拽到区域①中上传。</p> <div> <div> <i></i> </div> <div> <strong>说明 </strong> <ul> <li><p>支持Excel、CSV、PDF、Word、Markdown、TXT、图片等多种文件格式。</p></li> <li><p>单次最多上传10个本地文件。</p></li> <li><p>单文件大小限制50MB以内。</p></li> </ul> </div> </div></td> </tr> <tr> <td><p>② 待上传文件列表</p></td> <td><p>此处展示了当前已选中并准备上传的文件队列。当队列中存在误选或不再需要使用的文件时，您可以通过点击该文件右侧的<img>图标移除。</p></td> </tr> <tr> <td><p>③ 添加到</p></td> <td><p>指定文件上传后在文件列表目录中的存储位置。默认为根目录，也可以选择已有文件夹进行归类管理。</p></td> </tr> </tbody> </table>
3. 点击**上传** 按钮即可执行上传操作。系统将自动对当前上传文件进行学习，建议等系统完成学习后再基于该数据资产发起分析任务等操作。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1958025871/p1090778.png)

4. （可选）您可以对已上传的文件进行展示范围设置、编辑、协同授权等管理操作，具体操作说明请参见本文[管理数据资产](#70e3a2aba3hsm)。

### API数据

API数据即为通过API接口接入的外部数据资产，适用于需要对接第三方系统数据的场景，例如：通过API接口拉取CRM系统中的最新客户跟进记录。您可以在**API数据**页签下进行新增操作。

1. 点击页面右上角**连接API数据** 按钮。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9722204871/p1086361.png)

2. 在**连接API数据** 弹窗的输入框中，输入您想要连接的API地址或文档，点击![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5631204871/p1086329.png)图标发送，智能助手小Q即会自动解析该API中的连接参数并帮您尝试连接。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9722204871/p1086345.png)

   **说明**

   连接前，请检查API端口，并添加IP白名单列表。
   * 仅支持以下端口：443、80、3306、465、587、5432、7001。

   * 您需将Quick BI不同网络环境下的IP地址段添加至 API 的白名单：47.101.108.0/24、101.132.48.0/24、47.101.107.0/24、139.224.92.0/24、139.224.4.0/24、106.15.146.0/24、106.15.145.0/24、106.15.143.0/24、106.15.14.0/24、106.15.13.0/24、11.193.48.0/24、11.197.244.0/24、10.152.69.0/24、10.152.163.0/24、100.104.0.0/16。

3. 执行完毕后，小Q会为您输出连接方案及当前接口返回的字段清单，您可以在当前对话框中进行确认，无误后即可为当前API数据设置**名称** 及**保存路径** ；若方案存在需要修改的地方，也可以通过与小Q对话的方式对已生成的方案内容进行进一步调整。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5631204871/p1086360.png)

4. 点击**确认保存** 即可执行连接操作。系统将对当前API数据进行学习，建议等系统完成学习后再基于该数据资产发起分析任务等操作。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9722204871/p1086362.png)

5. （可选）您可以对已连接的API数据进行展示范围设置、编辑、协同授权等管理操作，具体操作说明请参见本文[管理数据资产](#70e3a2aba3hsm)。
