**技能广场** 是 Quick BI AIPro 的 AI 分析技能管理模块，位于**企业**视图下。技能是封装好的分析能力单元，您可以在对话中通过" / "指令等方式调用，实现特定场景的分析任务。本文将为您介绍如何查看、创建并安装技能。  

## **前提条件**
* 您已登录 Quick BI AIPro。

* 您至少拥有Quick BI AIPro的**基础功能**权限。

* 如需使用自定义技能，需企业管理员或技能创建者已将技能设为对您可见。

## 功能入口
在Quick BI AIPro的**企业** 页签下，点击左侧导航栏中的**技能广场**。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3030966871/p1094381.png)

## 操作说明
在**技能广场** 页面，您可以查看所有有权限的技能，包括**内置** 和**自定义**技能。

### 自定义技能

**自定义**技能是企业自行创建的业务场景分析技能。支持通过以下方式创建自定义技能。

* **企业上传自定义技能**

  * **在管理中心** \>**技能关联** 页面单击**添加技能** 图标，上传并创建技能。具体请参见[技能管理](https://help.aliyun.com/document_detail/3045440.html)。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4571204871/p1086575.png)

  * 上传后，您可以修改**可见范围** 并让用户进行**安装**。

* **个人上传自定义技能**

  * **方式一：对话中创建个人技能**

    * 在**我的** \>**新建任务**页面的对话框里，输入生成技能相关的指令。

      例如，输入："帮我将以上分析逻辑生成一个技能"。系统将自动创建技能。

      ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0961204871/p1086343.png)
    * 生成后，您可以修改技能名称，单击**确认保存** 后，该技能将被封装并供调用。您可以在**我的技能**中进行管理。

      ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9861204871/p1086341.png)
  * **方式二：通过上传技能包创建个人技能**

    **在我的** \>**我的技能** 页面单击**添加技能** 图标，上传并创建技能。具体请参见[我的技能](https://help.aliyun.com/document_detail/3045430.html)。  
    **说明**

    仅支持 .zip（≤5MB）和 .md / .markdown（≤10MB）格式。

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2141204871/p1086320.png)

### 查看并管理技能

* 您可以通过**搜索**功能，快速定位到相应技能。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4571204871/p1086593.png)
* 支持通过筛选**安装状态** ，分别查看**已安装** 和**未安装**的技能。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4571204871/p1086594.png)
  * 已安装的技能仅支持**查看**。

  * 未安装的技能支持**查看** 和**安装**。

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4571204871/p1086596.png)

    安装后，您可以在**我的** \>**我的技能** \>**我安装的**页面中查看安装的技能，并支持在对话中进行调用。

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4571204871/p1086597.png)
