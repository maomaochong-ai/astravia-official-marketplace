## 新增内容
* 数据源
  * 新增自建数据源Impala。 请参见[自建数据源Impala](https://help.aliyun.com/document_detail/202680.html#task-2492443 "本文为您介绍如何创建自建数据源Impala。仅专业版和高级版的群空间支持创建自建数据源Impala。")。

  * 新增加速缓存功能，支持使用DLA加速MaxCompute数据查询。
* 数据集  
  设置数据脱敏后，以下情况支持显示：
  * 新交叉表会有特别提示，翻牌器支持脱敏显示。
  * 自助取数下载结果支持脱敏显示。
  * 数据中包含脱敏字段时，电子表格的图表、全屏仪表板中图表均报错显示。

  * 新增Tab内查询控件。请参见[Tab内创建查询控件](https://help.aliyun.com/document_detail/201488.html#task-2383818 "通过查询控件可以查询单个或多个图表中的数据，一个Tab中可以添加多个查询控件。")。
  * 查询控件其他新功能

    * 级联查询子层级支持显示默认值。

* 移动端
  * 移动端支持展示组合图。
  * 在PC端配置Story Builder后，在移动端打开时支持快速锚点定位。
  * 移动端支持展示Tab内查询控件。
  * 移动端所有线柱面条系列图表及组合图支持手势缩放，包括：
    * 双指放大。![缩放](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2520111161/p226748.png)
    * 长按tooltip连续滑动实现快速切换维值。![销售信息](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0725724561/p227237.gif)

  * 移动端饼图支持联动跳转下钻。
  * 数据脱敏的图表统一报错处理。
* 开放服务  
  原 开放服务模块改名为 开发者中心模块，其下新增自定义组件、嵌入渠道功能。
  * 自定义组件：支持自定义报表使用的组件，将开发好的组件注册、发布到Quick BI后使用。
  * 嵌入渠道：报表嵌入第三方系统时，支持一键跳转到第三方渠道。请参见[发布渠道](https://help.aliyun.com/document_detail/201492.html#task-2036909 "Quick BI支持多渠道嵌入报表。本文以Quick Audience为例介绍如何将Quick BI中的仪表板嵌入到Quick Audience中。")。

## 下线功能
* 下线查询控件的移动到功能：后续不支持将查询控件移动到Tab内，支持Tab内直接新建查询控件。
