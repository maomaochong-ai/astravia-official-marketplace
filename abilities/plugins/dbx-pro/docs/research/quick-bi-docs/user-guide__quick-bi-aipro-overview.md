Quick BI AIPro 是阿里云智能新一代 AI 驱动的商业智能分析平台，将传统 BI 数据分析能力与大语言模型深度结合。您可通过自然语言对话完成数据查询、可视化分析、报告生成等全流程操作，实现从「概览→拆解→归因→诊断→行动」的完整分析路径。  

## **使用场景**
* 业务负责人在早会前 5 分钟问「上周各区域销售同比」，直接拿到图表与归因。

* 运营同学问「为什么华东 GMV 下滑」，自动下钻到品类、渠道、门店三级归因。

* 财务同学通过对话生成「月度经营看板」，并通过对话生成每月 1 号的月报推送任务。

* **分析模式切换：** 支持**对话模式** 和**画布模式**。

  * **对话模式**：Quick BI AIPro 的核心功能模块。您可以用自然语言描述分析需求，AI 将自动完成数据查询、计算分析，并返回结构化的分析结果。支持多轮追问、作品输出、一键订阅等能力。

  * **画布模式**：智能对话分析的可视化工作台，可以将对话中产生的分析结果移入画布进行自由排布、组合呈现，承接对话过程中产生的所有产物（图表、文字、报告、报表、HTML、文件等），并支持基于产物的组织、追问、组合与生成新作品。

* **意图识别能力**：AIPro 通过对话意图识别，将用户在对话中输入的自然语言自动映射到相应的下游操作（如"数据查询""可视化""诊断""生成报告"或"创建定时任务"），无需用户手动切换至具体功能页面。根据提问内容的不同，系统可返回相应的分析结果。

* **多形式结果返回**：支持生成文档报告、可视化报表、HTML报告、PPT文稿、技能等。

* **消费分析结果**：支持分享、订阅、下载等能力。

* **历史记录查看** ：您可以在左侧导航栏下方查看并搜索**任务** 和**订阅** 的历史记录。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1704864871/p1088396.png)
