数据广场是Quick BI AIPro的企业级数据资产浏览平台，分析者可以在此查看企业内各类数据资源（包括数据集、仪表板、数据表组合、文件和API数据），并按需添加到[我的数据](https://help.aliyun.com/document_detail/3045429.html)中使用。本文将为您介绍具体操作步骤。  

## **前提条件**
* **版本购买**：您所在的组织已购买Quick BI AIPro版本。

* **权限配置** ：您至少拥有Quick BI AIPro的**基础功能**权限。

* **资产发布** ：对于数据表组合、文件、API数据，需管理员已在**管理中心** 进行了发布操作，分析者才能在数据广场中查看到相关数据资产，具体操作说明请参见[数据管理](https://help.aliyun.com/document_detail/3045437.html)。

* **协同授权** ：对于空间数据资产（数据集、仪表板），分析者需具备目标数据资产的使用权限，才能将该资产成功添加至**我的数据** 中使用。添加仪表板时只校验仪表板本身的权限，不再要求具备其底层数据集的权限。且空间内数据资产在数据广场中的可见逻辑，还受到当前工作空间的**空间模式** 影响：![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6422204871/p1086461.png)

  * 当工作空间为**协同模式** 且**勾选了**数据广场全量用户可见，则组织内所有成员可查看到空间内数据（包括无使用权限部分）。

  * 当工作空间为**协同模式** 且**未勾选**数据广场全量用户可见，则仅空间内成员可查看到空间内数据（包括无权限部分），被赋予使用权限的空间外用户可查看到有权限的数据。

  * 当工作空间为**私密模式**，则组织内所有成员都仅能查看到拥有使用权限的部分资源。

## 功能入口
在Quick BI AIPro的**企业** 页签下，点击左侧导航栏中的**数据广场** 。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6168025871/p1090784.png)
