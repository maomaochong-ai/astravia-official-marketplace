## 本期概览
本期一句话概览：**AIPro 围绕数据资产、AI 报表编辑、分析主题与协作渠道继续升级，数据查找和权限管理更清晰，报表生成后的二次编辑更灵活**。

### 本期亮点

1. **数据资产与数据广场体验升级**：我的数据、数据广场、数据管理和预配置数据资产统一优化列表、筛选、预览和详情展示，找数据、看资产状态和处理权限申请更顺手。

2. **AI 报表支持配置项编辑**：新增配置项编辑和代码编辑能力。生成报表后，可通过配置项修改图表类型、字段、样式和标题，也可直接编辑代码进行更灵活的调整；所有修改均即时生效，可直接在报表中查看效果。

   ![报表编辑态配置区：数据页签字段与配置项编辑](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1781409871/p1100631.png)
3. **AI 报表支持自定义图表**：突破系统内置图表类型的限制，用户可便捷上传更符合业务需求的图表，并在报表生成和二次编辑中直接使用，还可在团队内共享复用，让数据以更丰富、更贴合场景的方式呈现。

4. **仪表板小Q解读升级为 AIPro**：在 AIPro 版本中，仪表板小Q解读升级为 AIPro，用户可以快速打开 AIPro，直接针对仪表板数据进行洞察分析，支持追问、联网、使用技能、使用 MCP 等能力。一句话就能生成图文并茂的报告、定位看板异常并归因。

5. **AIPro 新增分析主题能力**：业务分析师可按业务域封装数据、知识、技能与分析规则，并统一创建、管理和发布。通过限定主题上下文，减少无关信息干扰与跨场景口径冲突，使选表、指标理解和规则调用更加准确；同时支持同一数据面向财务、销售、人力等不同业务场景配置独立口径，沉淀可跨角色、跨场景复用的组织级分析能力。业务用户可在主题广场申请使用，并在对话生成报表时选择对应主题。

6. **频道管理支持飞书渠道**：频道管理新增飞书渠道与飞书配置指南，可按飞书自建应用、机器人、权限、事件订阅和回调配置完成接入。支持通过飞书机器人使用 AIPro，在 AIPro 中完成绑定后即可对话，会话记录与记忆在 web 端和飞书端双向同步。

## Quick BI AIPro 功能更新
### 问数与对话

* **仪表板解读升级为 AIPro**：在 AIPro 版本中，仪表板小Q解读升级为 AIPro，可使用技能选择、MCP、联网和附件等能力；仪表板嵌出场景，也支持在仪表板上直接使用 AIPro 进行洞察分析。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1100808.png)

  请参见[仪表板AIPro](https://help.aliyun.com/document_detail/3058813.html)。
* **分析主题的预览和使用**：用户可以在对话输入框预览和选中分析主题，使用主题上下文进行分析。用户可以进入企业主题广场发现和申请更多分析主题。

* **报告内 AI 入口统一为分析助手**：报告编辑页的报告编辑模式下，问数、解读入口统一为「分析助手」，划词工具栏、图表菜单和顶部工具栏入口统一收敛。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1100803.png)

  请参见[对话模式](https://help.aliyun.com/document_detail/3045431.html)。
* **洞察分析术语更清晰** ：指标洞察和经营洞察中的「基准组 / 对照组」调整为「当前周期 / 对比周期」等表达，减少业务理解歧义。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1100856.png)

  请参见[指标洞察](https://help.aliyun.com/document_detail/2985099.html)、[经营洞察](https://help.aliyun.com/document_detail/3023171.html)。
* **深度洞察支持异常检测和趋势预测**：对话中针对指标波动类问题使用深度洞察分析，基于已配置的指标洞察逻辑进行归因计算，并可对指标进行异常检测和趋势预测；AI 报表的图表内也支持使用深度洞察，分析结果可在图表和表格之间切换查看。

  ![对话中深度洞察分析的异常检测与趋势预测结果](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1781409871/p1101556.png)

  请参见[对话模式](https://help.aliyun.com/document_detail/3045431.html)。

### AI 报表

* **AI 报表支持配置项编辑** ：新增配置项编辑和代码编辑能力。生成报表后，可通过配置项修改图表类型、字段、样式和标题，也可直接编辑代码进行更灵活的调整；所有修改均即时生效，可直接在报表中查看效果。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1101771.png)

  请参见[对话模式](https://help.aliyun.com/document_detail/3045431.html)。
* **AI 报表支持自定义图表**：支持上传自定义图表，用于报表生成和二次编辑。用户可将符合自身业务需求的图表上传至平台供组织成员共享复用，突破内置图表类型的限制。此外，还提供了自定义图表生成 Skill，用户无需深入理解代码，只需在 AI 编程工具中通过自然语言描述需求，即可快速完成图表生成和调试。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1101772.png)

  请参见[管理自定义图表](https://help.aliyun.com/document_detail/3055219.html)、[图表广场](https://help.aliyun.com/document_detail/3055220.html)、[我的图表](https://help.aliyun.com/document_detail/3055221.html)。
* **图表内深度洞察** ：在报表中，将鼠标移动至图表上并单击图标，可选择**异常检测** 、**趋势预测** 或**归因分析**：异常与预测结果回显在对应图表上（仅支持时间维度的折线图），归因结果以文字说明与数据表格呈现。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4655409871/p1101773.png)
