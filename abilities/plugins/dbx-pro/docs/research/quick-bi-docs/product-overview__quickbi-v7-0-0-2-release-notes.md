## 本期概览
本期一句话概览：**AIPro 新增极速提问模式，对话文件交互更顺手，钉钉频道让 AIPro 走进 IM**。

### 本期亮点

1. **新增极速提问模式**：支持标准 / 极速两档提问模式，切换极速模式后问数响应更快，配套模型与相应能力由系统预置，适合只想快速提问的场景。

2. **对话文件支持拖拽上传与预览**：Word、CSV、PDF、PPT、图片、HTML 等文件可直接拖入对话，上传后在消息中即可预览内容，不用再逐个打开确认。

3. **AIPro 接入钉钉频道**：支持通过钉钉机器人使用 AIPro，在钉钉中完成绑定后即可对话，会话与记忆双向同步。

### 数据广场

* **仪表板消费逻辑优化**：仪表板作为数据资产时，仅使用仪表板中的数据进行分析，不再下探到底层数据集。因此，具有仪表板使用权限即可添加，无需再单独开通底层数据集权限。

  请参见[数据广场](https://help.aliyun.com/document_detail/3045433.html)。
* **数据广场页面改版**：数据广场全新卡片布局，预览数据更清晰，查找数据资产更高效。
