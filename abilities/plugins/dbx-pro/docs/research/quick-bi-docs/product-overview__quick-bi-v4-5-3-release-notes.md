## **发布日期**
2023年1月10日

## 重点升级概览
* 可视化图表引入更多分析能力

  * 支持新高级计算能力，支持累计、Top N、排名、百分位和占比计算。

  * 符号地图支持按照维度生成不同的符号样式，用于区分不同地理位置的业务属性。

  * 排行榜数据展示条数扩展，支持展示500条。

* 大屏搭建效率\&查看效果提升

  * 大屏地图支持多图层，打造更强的氛围感和酷炫效果。

  * 数据大屏支持全局数据集替换。

  * 主题色新增\&微调。

* 数据构建能力拓展

  * 数据集支持自定义关联条件和关联前过滤。

  * 支持数据集信息自动同步到图表，包括维度度量名称以及描述、度量类型和数值格式。

  * 数据源支持Kingbase V8版本。

  * 数据源新增开启文件上传入口配置项。

  * Quick引擎抽取加速支持Polar DB for MySQL。

  * 新组织默认关闭全局缓存。

  * 数据准备：专业版基础任务数调整为10个，可额外增购，试用用户任务数调整为3个。

* 组织管理能力提升

  * 组织管理性能分析Tab独立。

  * 用户分析支持选择所有用户，一次性导出基于所有用户的访问统计数据。

* 办公协同能力增强，钉钉/企微/飞书对接更完善

  * 钉钉、企微、飞书，支持企业绑定、编辑、解绑 \& 订阅配置。

  * 钉钉/企微/飞书，支持OA审批对接。

* 体验优化

  * 列表页操作调整。

  * PC端首页报表查看支持千人千面。
