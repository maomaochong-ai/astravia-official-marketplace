画布模式是智能对话分析的可视化工作台，您可以将对话中产生的分析结果移入画布进行自由排布、组合呈现。本文为您介绍画布模式的相关操作。  

## **前提条件**
已通过[对话模式](https://help.aliyun.com/document_detail/3045431.html)产生分析结果。

## 使用场景
在AI Pro里，对话是一问一答的方式：问一句，它帮忙查数、解读、生成一张图或一份报表，适合快速拿到结果。但真正做深入分析时，往往要问很多轮、陆续生成好多张图，这时候对话流就不好用了------图表散落在一长串问答里，翻起来费劲，也没有地方把好几张图摆在一起对照着看、接着分析。 画布就是用来解决这个问题的，可以把它理解成对话旁边的一块"大桌面"：对话里生成的图表和结果都能放到这块桌面上，摊开来整体查看，围绕这些已有的图继续追问、继续挖，还能把它们拼装成一份新的作品。具体使用场景如下：

* **深入追问**：选中一张或多张图表直接接着问，分析思路连续不被打断，不用在对话中来回滚动。

* **理清脉络**：基于某张图追问时，会自动连出图与图之间的关系线；顺着连线还能看血缘------这张图是从哪个问题引出的、后续又衍生出哪些分析，点图还能跳回当时那轮对话，来龙去脉一目了然。

* **自由组织**：把想一起看的图拖到一处对照，把和分析无关的移出画布，只留下真正在推进的内容。

* **组合成果**：一次选中多张图表，合并生成最终产物。

## 功能介绍
### 模式切换

画布支持**沉浸模式** 和**非沉浸模式**。

* **沉浸模式**：界面上仅显示分析画布。您可以在沉浸模式中，专注于画布本身进行分析。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088440.png)

  在沉浸模式下，支持以下操作：
  * 您可以继续进行对话。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088439.png)

  * 点击卡片，卡片标签会出现在对话框中，您可针对选中的某个或多个卡片进行追问。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088442.png)

  * 点击对话框左上方的"**执行中**"，可以查看任务的执行过程。

    ![427](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088445.gif)
  * 单击右上角![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8171204871/p1086481.png)图标可退出沉浸模式。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088448.png)

* **非沉浸模式**：界面上显示双分栏布局，您可以在左侧对话框中发起对话，也可直接在分析画布的图表上进行快捷对话。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088450.png)

  在非沉浸模式下，支持以下操作：
  * 点击对话中的图表或产物标签，即可自动定位到画布中对应的卡片。

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088452.png)
  * 在卡片下方可以输入问题**继续分析**。

    ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088453.png)
  * 支持单击右上角![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8171204871/p1086482.png)图标进入再次沉浸模式。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1973264871/p1088454.png)
