## 重点升级概览
* 开发\&访问入口页升级，提升查找和编辑效率。  
  为更好的拟真数据协作工作体验，全新推出 我的看板、 工作台模式：
  * 我的看板业务目录让数据内容导航清晰明了，快速定位所需数据内容，提升访问用户查找效率。
  * 工作台模式让分析师集中管理资源，提升编辑效率。
  升级后带来极致的效率改革，贴近不同角色用户的协作链路，让信息效率最大化。
* 智能见解、趋势、数图结合，数据驱动决策更高效。
  * 全新推出**趋势分析表格**，经营趋势一目了然。
  * 交叉表新增迷你图，数字+图形的方式让分析更加可视。
  * 新增图表级见解，高效洞察数据。
* 多端能力持续升级。
  * 继企业微信后，推出飞书无缝对接。
  * 移动端新增主题、自定义门户，让数据触达更便捷。
* Quick引擎让数据查询速度加倍。 全新推出Quick引擎，引入列式存储计算引擎作为加速方案，亿级数据秒级响应的顺滑体验，让分析查询速度更加高效。

* 安全持续升级，全局管控资源权限。 全新推出权限集中管控模块：从资源到人精细化管控门户数据源、仪表板、电子表格等，管理员可快速把控全局权限情况，更安全并更高效的进行权限管理配置。

* 区块嵌入及多账号集成，让信息更加一体化 为打穿BI最后一公里，除页面嵌入外，新增区块嵌入，将区块图表与自建系统、产品进行集成；通过账号、嵌入集成满足企业内部建立统一平台的场景诉求，让看数场景紧密融入业。
