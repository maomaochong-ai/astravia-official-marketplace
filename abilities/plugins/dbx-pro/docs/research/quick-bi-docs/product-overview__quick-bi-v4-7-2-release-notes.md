## 重点升级概览
* 交互式填报\&数据填报体验优化

  * 交互式填报新增填报提交类型。

  * 填报数据管理页面样式体验优化。

* 可视化配置能力提升

  * 主题设计优化主题标题背景、容器背景支持自定义图片。

  * 支持上传svg格式图片。

* 监控告警能力优化

  * 明细表创建监控时，支持修改聚合方式。
