## 变更内容
本期一句话概览：**对话里生成的技能会以卡片形态沉淀；对话分享等协作与管控链路全面补齐**。

### 本期亮点

**新增"数据故事生成"Skill**：使用该Skill，一键生成可动态播放的动画数据解读，识别数据中的异常和关键信息。说「用数据故事带我看看」即可触发。

### 问数与对话

* **对话分享优化**：对话中的仪表板、HTML、报告等数据作品，分享后接收方无需再校验自身权限即可查看；私密链接和公开链接的体验统一，分享页面仅保留查看能力，编辑、去往我的分析、版本记录等操作入口自动隐藏。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2857117871/p1095766.png)

  请参见[对话模式](https://help.aliyun.com/document_detail/3045431.html)。
* **对话中支持归因分析**：通过 Skill 调用已配置的指标洞察逻辑，在对话里直接问「上个月 GMV 为什么跌了」「帮我分析一下本月销售额异常的原因」，即可输出归因分析报告；未命中配置时也会用默认规则按数据集全部维度进行归因计算。

  ![归因报告](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0613446871/p1094195.png)

  请参见[生成归因报告](https://help.aliyun.com/document_detail/3045431.html#vkq38digoaopy)。
* **新增"数据故事生成"Skill**：使用该Skill，将复杂数据一键转化为图文并茂的动画解读，帮助您更直观地理解数据背后的含义。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0613446871/p1094431.png)

  请参见[生成数据故事](https://help.aliyun.com/document_detail/3045431.html#c3r7m2n8k4vt9)。

### MCP 广场

* **我的 MCP 添加入口增加企业 MCP 广场选项** ：在个人 MCP 管理中添加连接器时，除了原有入口，新增「企业 MCP 广场」选项，方便直接使用企业已配置的 MCP。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0613446871/p1094423.png)

### 管理后台

**说明**

适用对象：平台管理员和数据管理员。

* **普通用户数据集使用权限支持可选** ：组织管理员可在角色权限中，将普通用户角色的「数据集---使用权限」设置为可选。默认不勾选，开启后该组织下的普通用户即可在 AIPro 中使用对应数据集。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0613446871/p1094422.png)
