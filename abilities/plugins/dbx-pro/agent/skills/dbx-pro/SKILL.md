# 数据库工作台 — dbx-pro

通过 dbx-pro 数据库工作台与用户已配置的数据库连接交互。支持 84 种数据库（MySQL、PostgreSQL、ClickHouse、Snowflake、MongoDB 等）。

## 核心能力

### 1. 查询执行（dbx_query）
执行 SQL 查询并返回结果。支持 SELECT、INSERT、UPDATE、DELETE、DDL 等所有 SQL 语句。

**使用场景：**
- 用户要求查询数据、统计信息
- 用户要求修改数据（需确认）
- 用户要求创建/修改表结构

**注意事项：**
- 默认只读模式，写操作需要用户确认
- 结果默认限制 1000 行，可通过 limit 参数调整
- 查询超时默认 30 秒
- 始终展示列名和前几行数据，帮助用户理解结果

### 2. 表结构浏览（dbx_schema）
获取数据库的表、列、索引、约束等结构信息。

**使用场景：**
- 用户询问某个表有哪些字段
- 用户需要了解数据库结构以编写 SQL
- 用户要求查看索引或约束

**操作模式：**
- `list_tables` — 列出所有表
- `describe_table` — 查看表的列定义
- `list_indexes` — 查看索引
- `list_schemas` — 列出所有 schema
- `get_ddl` — 获取建表语句

### 3. 查询分析（dbx_explain）
分析 SQL 查询的执行计划，提供优化建议。

**使用场景：**
- 用户询问查询为什么慢
- 用户要求优化 SQL
- 用户要求分析索引使用情况

**输出内容：**
- 执行计划（EXPLAIN 结果）
- 性能瓶颈识别
- 索引建议
- SQL 重写建议

### 4. 数据库画像（dbx_profile）
对表或数据库进行统计分析，生成数据画像。

**使用场景：**
- 用户要求了解数据分布
- 用户要求检查数据质量
- 用户要求统计信息汇总

**分析内容：**
- 行数统计
- 列的空值率、唯一值数
- 数据分布（数值型的最小/最大/平均值，分位值）
- 字符串型的长度分布、常见值

## 工作流程

### 自然语言转 SQL
当用户用自然语言描述查询需求时：

1. **先获取表结构** — 使用 `dbx_schema` 的 `describe_table` 了解相关表的列名和类型
2. **生成 SQL** — 基于表结构生成 SQL，注意：
   - 使用正确的列名和类型
   - 注意 NULL 处理
   - 使用合适的 JOIN 条件
   - 添加合理的 WHERE 过滤
3. **执行并展示** — 使用 `dbx_query` 执行，展示结果
4. **迭代优化** — 如果结果不符合预期，根据用户反馈调整

### 查询优化流程
当用户要求优化查询时：

1. **获取原始 SQL** — 确认要优化的 SQL
2. **分析执行计划** — 使用 `dbx_explain` 获取执行计划
3. **识别瓶颈** — 分析全表扫描、嵌套循环、排序等
4. **提出建议** — 给出索引建议或 SQL 重写方案
5. **验证效果** — 执行优化后的 SQL，对比性能

### 数据质量检查流程
当用户要求检查数据质量时：

1. **获取表结构** — 了解表的列定义和约束
2. **执行画像分析** — 使用 `dbx_profile` 获取统计数据
3. **识别问题** — 检查空值率、异常值、重复数据
4. **生成报告** — 汇总发现的问题和建议

## 安全准则

- **写操作前必须确认** — INSERT/UPDATE/DELETE/DDL 执行前向用户确认
- **生产环境标记** — 如果连接标记为生产环境，额外提醒风险
- **只读模式优先** — 默认使用只读模式，仅在用户明确要求时开启写权限
- **不暴露敏感信息** — 不在输出中显示密码、连接字符串等敏感配置
- **限制结果集** — 大表查询默认限制行数，避免内存溢出

## 连接管理

用户可以在数据库工作台中配置多个连接。每个连接包含：
- 连接名称（用户自定义）
- 数据库类型（MySQL、PostgreSQL 等）
- 主机、端口、数据库名
- 认证信息（用户名、密码）

使用工具时，通过 `connection_name` 参数指定要使用的连接。如果用户没有指定连接，使用当前活跃连接。

## 输出格式

- **查询结果** — 以表格形式展示，包含列名和数据
- **表结构** — 以列表形式展示列名、类型、是否可空、默认值
- **执行计划** — 以树形结构展示，标注关键节点
- **优化建议** — 分条列出，每条包含问题描述和建议操作
- **数据画像** — 以统计表格形式展示，包含行数、空值率、分布信息
