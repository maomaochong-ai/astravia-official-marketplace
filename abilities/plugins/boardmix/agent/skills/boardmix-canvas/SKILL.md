# Canvas work

画布里的图形是像素，我们读不到图层结构（`docs/adr/boardmix/bm-0001`）。
但产品自己有一个**文本 → 原生图形**的转换器：它解析 Mermaid（`docs/adr/boardmix/bm-0002`）。
所以这件事的正确做法不是点一百下，而是**写一份 Mermaid，交给它**。

## 一条规则

**先产出 Mermaid，再谈怎么送进去。** 一段"我会怎么画"的描述，对用户值零。

数量也先问清：三类问题以内（要什么图、边界在哪、要不要能继续编辑），然后交付。

## 产品能吃哪六种

产品的文案原文：`支持解析mermaid格式的流程图、时序图、ER图、类图、饼图和象限图。`

| 用户要的 | Mermaid 第一行 |
| --- | --- |
| 流程、泳道、架构 | `flowchart TD` / `flowchart LR` / `graph LR` |
| 时序、交互顺序 | `sequenceDiagram` |
| 数据模型 | `erDiagram` |
| 类、继承 | `classDiagram` |
| 占比 | `pie` |
| 二维定位（重要度×紧急度） | `quadrantChart` |

别的图型不承诺——`boardmix_diagram` 会在第一行就拒收，并告诉你它只认这六种。

## 两段式，别合成一步

```json
{ "text": "flowchart TD\n  A[提需求]-->B{评审}\n  B -->|通过| C[开发]" , "title": "需求流程" }
```
→ `.boardmix/diagrams/需求流程.mmd` 落盘，返回元素估算与文件路径。**画布上什么都没有**，这是默认。

```json
{ "text": "…", "apply": true }
```
→ 再往画布投一次真实粘贴，然后拍图。`applied: true` 只表示粘贴被接受，**形状对不对要看那张 PNG**。

- `staged.elements` 是节点 + 连线的粗估；免费档每文件 150 元素，超了会在 `overBudget` 里说明。
  在交付前说一句，比用户半小时后撞墙好。
- 粘贴没被接受：把 `.mmd` 路径给用户，让他自己导入。**不要重放同一次粘贴。**

## 元素预算，先说

- 免费账户：3 个可编辑文件、**每文件 150 元素**。
- 交出去的图**≤ 60 元素**：吃掉一半额度的图，用户改不动。
- 超了就说：「这张图约 80 个元素，超过免费额度的一半，继续加需要会员。」

## 面板路径，不给坐标

| 用户要找的 | 帮助中心分组 |
| --- | --- |
| 思维导图、流程图、图形、便签、文档卡片、画笔 | 创作工具 |
| 素材库、模板、嵌入 | 资源与素材 |
| 画布基础、画布模式 | 画布设置 |
| 评论、投票、演示、分组讨论 | 协作与交流 |

分组名能扛住改版，坐标扛不住。

## 完成的样子

- Mermaid 在回复里，或 `.mmd` 在项目里（`boardmix_diagram` 给的那条路径）；
- 元素数说出来了，且在额度内；
- 落地方式写清（导入 / 粘贴 / AI），没有含糊；
- 如果走 `apply`，你看过那张 `shot`。

## 不要做

- 不要猜板上已经有什么。"接着上次那张图"= `boardmix_shot` 拍一张再看，或让用户描述。
- 不要说 `已帮你画好了` / `已生成图表`——除非截图里看见了。
- 不要把图片、base64 当交付物：它们落不到画布上，也不能编辑。
- 不要用 `粘贴为 Markdown` 之类的文案来暗示"粘文字就会变图"。文本粘贴是格式选项；
  真正会变成图形的是 Mermaid，走 `boardmix_diagram`。
