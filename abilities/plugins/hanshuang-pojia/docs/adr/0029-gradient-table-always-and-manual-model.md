# 0029 — 梯度表始终在场、模型只由人填、顶栏不再重复发送

- 状态：已采纳
- 日期：2026-11-22
- 版本：2.17.42
- 相关：0024（对照表以对话为准）、0026（拒绝后自动探测）、0027（六档与两阶段闭环）、0028（面板观感）

## 背景

用户报了三件看起来无关的事，实际是同一类问题：**一个功能的存在取决于它旁边的条件。**

1. **拒答梯度表格不见了。** 它住在提示词页的「注入」视图里，而这一页默认停在「库」视图。
   就算切到注入视图，表格也被包在「有记录或有实时对照」的三元里；只在对话里跑过一次时，
   行又只从落盘的 `advice` 取，于是显示「这一次探测没有拿到可判定的回复」。
   没有会话时更直接：整块卡片只剩一句空态文案。
2. **模型被宿主配置牵着走。** 面板预填宿主当前模型、并在宿主换模型时自动覆盖 —— 用户明确要求这一栏只能自己填。
3. **顶栏那个「发送到对话」没有用。** 它发的是 `continue` 模板，跟用户在页面上正在做的事没有关系；
   每个页面自己的动作（解释、按方法实施、重测某一档）都带上下文，顶栏那枚是重复且更差的一条路。

## 决策

### D1 表格永远在

`ProbeRefusalCard` 的对照表无条件渲染。行来自三处，形状统一成 `TableRow`：

| 输入 | 用途 |
| --- | --- |
| 有落盘记录 | 那次探测的每一档，含措施档位 |
| 只有实时对照（对话里刚跑、还没落盘） | 对话里那几行；这是上一版显示「没有可判定的行」的场景 |
| 两者都没有 | **这一轮要跑的档位**，判定列写「未测」 |

判定列空着和「表格不存在」是两件完全不同的事：前者告诉用户「还没跑」，
后者让人以为功能被删了。未测的档位同时是「接下来要测什么」的清单。

### D2 卡片提到视图分支之外

提示词页有两级结构：库 / 注入。梯度对照不是注入的子步骤 —— 它是这一页的一等公民，
所以渲染在两个视图共用的位置。库视图里它排在提示词列表之前。

### D3 模型只由人填

删掉整条「宿主模型」链路，而不是把它藏起来：

- 读：`bridge.hostModel()`、`model.probe.hostModel`、卡片里的预填条与跟随 effect；
- 写：`registerSystemPromptProvider` 里那份 `workbench/host-model.json` 快照；
- 存：`storage-layout` 的 `hostModel` 键（会话作用域），以及它的清理项；
- 契约：`followHostModel` 与 `HostModelSnapshot`。

理由不是「怕麻烦」，是它**没有真正工作**：快照确实每轮写，但面板读的是一个按会话分文件的路径，
而写的是插件作用域的单文件 —— 两边从来没对上过。删掉一个读不到的东西，比留一个永远为空的预填条诚实。

表格顶部「记录来自 <模型>」的旧模型提示保留，但比较对象改成**表单里那个手填的模型**：
记录是 `gpt-4o` 而你现在要测 `claude-…`，那就该提示，这跟宿主用什么是两件事。

### D4 顶栏不再有发送

`TopBar` 只留面包屑 + 对话状态。发送入口全部在页面上，且都带上下文：

- 提示词页：梯度「跑一次」「交给对话继续分析」；
- 发现页：观测行各自的「让对话解释 / 接着做」；
- 文档 / 案例 / 样本：右键菜单与行内按钮。

`SendPromptDialog`（发送前可编辑的那个弹窗）随之删除 —— 它唯一的调用点就是顶栏那枚按钮。
`model.previewPrompt` 也一并移除；`askText` 保留，它是所有页面动作的出口。

### D5 案例阅读区只有一个滚动容器

阅读区外层写了 `h-full + overflow-y-auto`，正文自己又带一层 `overflow-y-auto`。
嵌套滚动容器里，外层吃掉高度、内层高度等于内容高，滚轮落在内层上什么也不动。
现在外层只负责传高度（`flex-1 min-h-0`），滚动交给正文，前置块一律 `shrink-0`。

## 后果

- 少了一份从未被读到的存储文件、一个 hook、一个弹窗组件、一个只有它用的 model 方法；
- 「表格不见了」这一类问题不再可能出现：它没有可以消失的分支；
- 模型栏的语义变成「你正在测谁」，而不是「宿主认为你在用什么」；
- 知识库阅读区在任何面板高度下都能滚 —— 三条静态契约（单滚动容器、前置块不收缩、正文可滚）写进了测试。

## 不做什么

- **不把梯度对照拆成独立页面**：它与提示词库共享「这次会话在测什么」的上下文，分成两页就要来回切；
- **不留「用宿主模型」按钮**：读不到就是读不到，给一个按了没反应的按钮比不给更差；
- **不恢复顶栏发送**：如果某个页面需要一句通用发送，那句话应该由那个页面写。
