# 0017：全侧栏的一致性标尺——七档字号、一种列宽、一种焦点色

- **状态：** 已接受
- **日期：** 2026-11-20
- **背景：** 逐个侧栏修完之后，把 98 个组件文件放在一起量了一遍：字号 14 档、统计卡列宽 4 种、焦点色 3 种、单选列表混用 `aria-pressed`。这些不是任何一个页面的 bug，是「没有标尺」。
- **适用：** `src/features/workbench/components/**`、`src/test/workbench/type-scale.test.ts`

## 问题（量出来的）

| 维度 | 修前 | 修后 |
|---|---|---|
| 字号档位 | **14**：9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 18 / 19 | **7**：9.5 / 10.5 / 11.5 / 12 / 13 / 14 / 18 |
| 统计卡列宽 | 4 种 `minmax(120/130/140/150px,1fr)` | 1 种 `minmax(140px,1fr)` |
| 输入框焦点色 | `accent` / `line-strong` / `purple` 三种 | `accent` 一种（purple 专属「当前激活的提示词」） |
| 单选列表语义 | `aria-pressed` / `aria-current` 混用 | 单选列表用 `aria-current`；开关与筛选 chips 保留 `aria-pressed` |
| 内边距档位 | 16 档（0–12） | 不动：`p-1.5` 与 `p-2` 是真实的设计差别，折叠会改密度 |

14 档字号的害处不是「看着乱」，而是**新增页面无法判断该用哪一档**：10 与 10.5 差 0.5px，肉眼无差，于是每个页面随手挑一个，差异继续累积。

## 决定

### D1 七档字号，每档有职责

| 档位 | 职责 | 典型用例 |
|---|---|---|
| 9.5 | 微型标注（等宽） | 偏移、计数、单行时间、`rule.id` |
| 10.5 | 元信息 | 卡内说明、字段标签、次要行 |
| 11.5 | 正文 | 列表主文字、按钮、正文默认 |
| 12 | 强调正文 / 小节标题 | 空态标题、弹窗小标题 |
| 13 | 卡片标题 | `Card` 的 `h2` |
| 14 | 页面标题 | 弹窗主标题、`h1.sr-only` 的视觉对应 |
| 18 | 统计数字 | `StatTile` 的数值 |

归一方式：只折叠**离最近档位 0.5px 且使用次数少**的值（9→9.5、10→10.5、11→11.5、12.5→12、13.5→13、15→14、19→18）。主导档位（10.5 / 11.5）保持不动，所以视觉密度不变。

### D2 门禁：`type-scale.test.ts`

列出八档以外的任何字号即失败，报「哪个文件用了哪档」。这条测试的意义不在今天，而在下一个人加页面时。

### D3 统计卡只有一种列宽

`StatTile` 是同一个组件，四张统计条不该有四种最小宽度。统一 140px（活动页原本就是这个值），窄面板靠 `auto-fit` 自动降列。

### D4 焦点色只认 accent

紫色在本产品里只有一个含义：当前激活的提示词。输入框聚焦用它，等于把「聚焦」画成「已激活」。三处 `focus:border-purple` 改 `focus:border-accent`。

### D5 超长正文按行截断渲染，不截断能力

反汇编预算是 500–60000 条指令。全量塞进 DOM 会让面板卡到无法滚动，所以**只渲染前 2000 行**，并在正文尾部说明；`copy` 与「交给对话」用的仍是全文。
判据：截断只影响「屏幕上画多少」，不影响读者能拿走什么。

### D6 字符串页加值搜索

这一页最常做的动作是「找那条带域名的串」，而原来只能按类型筛。搜索按值做子串匹配，与类型筛同时生效。

## 不做什么

- **不折叠内边距档位。** 16 档看着多，但 `p-1.5`（6px）与 `p-2`（8px）在密集列表里是能看出来的差别；折叠会改变所有页面的密度，而这一轮没有像素级回归手段。
- **不引入 Tailwind 主题扩展（`@theme`）去定义命名档位。** 插件产物要与宿主共用 Tailwind 运行时，`@theme` 在 MF 远程里有失效风险（ADR 0009 D2 已经吃过一次分块的亏）。字号仍写成 `text-[Npx]`，靠门禁约束。
- **不把 `FilterChips` 改成 radiogroup。** 筛选 chips 是「多个可独立开合的过滤器」的常见形态，`aria-pressed` 是 ARIA 认可的做法；只有真正的单选列表（文档、先例、函数）改成 `aria-current`。
- **不做虚拟滚动。** 2000 行截断已经解决卡死；虚拟滚动会引入第三方依赖或一整套手写测量逻辑，与「只渲染前 N 行」的收益比不划算。
