# 工作台面板 · 怎么用

面板是插件的操作界面：把工具结果放进可点、可筛、可导出的页面。你几乎不需要它才能干活——
但排查「功能到底有没有生效」时，它是最快的一站。

开发侧结构与状态边界见 [dev.md](dev.md)；逐页说明在随包手册
`src/content/docs/manual/PANEL-HANDBOOK.md`。

## 常用页与它解决的问题

| 我想…… | 去这一页 | 说明 |
| --- | --- | --- |
| 快速判断一个文件要不要细看 | 体检 | 格式、节区、导入导出、风险分与命中规则 |
| 看某个地址范围的指令 | 反汇编 | `full / fold / summary` 三档；长函数用 `fold` |
| 搜字符串 / 端点 | 字符串 | 可按 url / path / identifier 过滤 |
| 用对话的方式继续分析 | 对话 / 快捷提问 | 一键把面板里的上下文送进对话 |
| 看这次评估的目录与时间线 | 案卷 | 事件流 + 证据计数 |
| 查随包文档 | 文档 | 四个集合分开浏览，支持搜索 |
| 看提示词母本与备份 | 提示词 | 当前生效版本、历史、备份 |
| 确认插件真的加载对了 | 自检 | 四组数字：工具 / 资产 / 引擎 / 权限 |

## 自检页怎么读

四组，红在哪一组就说明问题在哪一层：

| 组 | 它证明什么 | 红了通常意味着 |
| --- | --- | --- |
| `tools` | 31 个工具是否注册齐全 | 插件加载失败或版本装错，不是工具链问题 |
| `assets` | 技能、知识库、文档索引、路由表指纹、14 条战例工程 | 同步脚本没跑，或加载了旧版资产 |
| `engine` | 运行时自检 | 环境 / 平台相关问题 |
| `permissions` | 权限清单与实际 API 的对应 | 权限声明与代码不一致 |

## 分寸

- **面板不是必经之路**：所有能力在对话里都能触发。面板的价值是「看得见、能复制、能导出」。
- **怀疑版本时看指纹，不看版本号**：路由表指纹（如 `table bfc208b6`）比版本字符串更能说明加载的是哪一份。
- **文件被宿主拒绝时不要硬试**：面板会区分「超出项目目录 / 文件过大 / 宿主拦截」，并给换条路的建议。

## 常见坑

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 反汇编只有文件偏移 | 地址映射没打开 | 打开映射后页头同时给 `file+0x…` 与 `vaddr` 和节区 |
| 页面数据是旧的 | 加载了旧资产 | 看自检页指纹；必要时重装 |
| 大文件打不开 | 宿主读取上限 | 用工具按需读（体检 / 字符串 / 反汇编范围），别整文件加载 |
| 活动流很长时页面变卡 | 活动条数有上限 | 清一次活动流即可，历史不影响结论 |
