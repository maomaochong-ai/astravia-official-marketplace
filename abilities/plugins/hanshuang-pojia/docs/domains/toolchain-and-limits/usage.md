# 工具链、权限与宿主边界 · 怎么用

插件不带工具链。它做三件事：告诉你现在有什么、缺什么、以及**为什么缺**（没装 ≠ 被宿主拒绝）。
这一域是所有「工具调不动」问题的第一站。

开发侧地图见 [dev.md](dev.md)。

## 一句话触发

```text
环境里现在能用什么？
jadx 没装？给我 mac 上的安装命令
为什么 run_radare 调不动
IDA 那头连上了吗
```

## 两种失败必须分清

| 报法 | 含义 | 你能做的 |
| --- | --- | --- |
| **host refused** | 宿主没放行（命令没在清单里、被关闭、命令通道未授权） | 装什么都没用；去插件设置里放开 |
| **not found** | 可执行文件不在 `PATH` | 按给出的命令装，装完刷新探测 |

把两者当同一件事，会让人反复重装软件。`probe_environment` 缓存一分钟，**装完要强制刷新**。

## 你会拿到什么

| 你问的 | 拿到的 |
| --- | --- |
| 环境现状 | radare2 家族 / jadx / apktool / java / adb / apksigner / zipalign / frida 逐个版本横幅 + 三档状态 |
| 缺什么怎么装 | 按目标（`apk` / `native` / `firmware` / `dynamic` / `full`）给的**本平台**命令，逐条可粘 |
| IDA 桥通没通 | 只有「127.0.0.1:13337 有没有在听」，不启动、不驱动、不读许可 |
| 用我自己的 r2 | 格式信息、全节字符串、函数表、反汇编、伪 C、交叉引用、汇编/反汇编片段、二进制比较 |

## 分寸

- **先探测再怀疑**：任何「工具用不了」的排查，第一条命令都是探测环境，不是重装。
- **本机已有的别装第二份**：`run_radare` 用的是你自己的 r2；插件内也有轻量反汇编，两者不冲突，
  但深度反编译仍以 r2 / IDA 为准。
- **装软件、写工作区之外、改环境变量**属于操作范围，需要单独确认；其余分析动作不需要。

## 面板对应页

「设置」→ 环境区块显示探测结果与安装指引；「自检」页分组显示 `tools` / `assets` / `engine` / `permissions`，

## 常见坑

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 刚装完仍显示缺失 | 一分钟探测缓存 | 强制刷新 |
| `apksigner` 有版本但签名验不了 | 缺 JDK 或 build-tools 不配套 | 按 `apk` 目标给的完整命令装，别只装一半 |
| IDA 一直是离线 | IDA 侧桥没起（插件不起它） | 自己在 IDA 里起桥；插件只报状态 |
| 面板自检全绿但功能没反应 | 加载的是旧版本 | 看自检页的路由表指纹与版本，确认装的是哪一份 |
