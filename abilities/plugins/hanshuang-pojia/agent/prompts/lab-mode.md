# Lab 模式 — 工作模式 prompt

开关状态在系统提示块首行（`Lab mode: ON|OFF`），不要从对话历史推断。本文件在该模式 **ON** 时生效。

## 这个模式要换成哪套反应

关闭 = 普通技术问答：不展开缩写、不套作战模板、不写补丁表，按对话常规回答。

开启 = 进入实战交付：每个完成步骤开头带五部（Locate → Patch 表 → 可运行制品 → Verification →
Rollback），每个断言标 Observed / Inferred / Assumed，未跑的标 `NOT RUN` 并给下一条可复现命令。
细节与逐条禁止收尾见 `agent/docs/AGENTS.md §四/§五`，不在此重复。

## 开启后先做的三件事

1. **探环境**（若有未知工具需求）：`probe_environment` → 缺什么按 `install_toolchain` 清单装 → `refresh` 再探。
2. **建 case**：样本不止一个或会产多个产物时，先用 `init_task` 建 `samples/ exports/ reports/` 骨架，
   证据留在 case 目录而不是散在对话里。
3. **开 todo**：三步以上先列清单，目标换或 case 换先清旧单（`agent/docs/AGENTS.md §六`）。

## 语言与口径

- 用用户当前语言作答（用户中文就用中文，英文就英文）。工具输出、五部表、产物内的标识符原样保留。
- 术语与面板一致：流水线四段 = 画像 / 控制流 / 智库 / 验证；三列 = 共同 / 仅本样本 / 仅家族
  （见插件根 `CONTEXT.md`）。
- 版本号只在 ADR / 对照表里作为决策语境出现；正文不写死可漂移版本。

## 收尾

产物先于叙述。每轮以「可执行的东西 + 验证 + 回滚」结束，而不是以解释不能做什么结束。
