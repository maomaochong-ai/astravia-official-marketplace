# 面板界面实战手册

> 面向「装好了但不知道点哪里」的使用者。回答每个页面**解决什么问题、控件怎么用、它背后是谁**。
> 术语见 `CONTEXT.md`；面板与对话的分工见 `USAGE.md`；案件契约见 `docs/contract/case-library.md`。
> 这三份都在仓库里，随包只发 `dist/`，面板内的「文档」页读不到它们。

面板共 **17 页**，侧栏分四组：**工作流**（总览 / 引导 / 智库 / 战例库 / 活动 / 提示词）、**分析**
（样本 / 发现 / 字符串 / 反汇编）、**取证**（清单 / 熵 / 签名 / 对比）、**系统**（自检 / 报告 / 设置）。
顶部 `PipelineBar` 用「画像 / 控制流 / 智库 / 验证」四段显示当前样本走到哪一步。

三条贯穿全panel 的约定：

- **AiButton**（带星标的按钮）不是本地计算，它把一段带上下文的问题**发进对话**给 Agent。点它之后
  答案在对话里出现，不在面板里。
- **面板只读已分析的字节**：所有页面读的都是同一次分析结果，切页面不会重新跑引擎。要重跑在
  「设置」里改模式后再分析。
- **每个空页都给出「为什么空」**，不是一片留白：没选样本、没分析、没有授权、工具没装，是四种不同的话。

## 一、工作流组

### 1. 总览 Overview

**回答**：这个样本有多危险、为什么、下一步做什么。

- 顶部风险分与等级（A–E），下面「驱动项」按权重排序列出贡献最大的发现。
- 「下一步」区给三个动作：加固建议、出报告、装工具链——分别对应 `ai.harden` / `ai.report` /
  `ai.toolchain`，点击把带上下文的请求发进对话。
- 没有样本时给的是「先选样本」，不是空图表。

**背后**：`domain/report` 的评分与 `buildReport`；不调用任何外部程序。

### 2. 引导 Guide

**回答**：这套东西到底怎么用，面板能做什么、对话能做什么。

- 一条主线流程图 + 「能做 / 不能做」两栏 + Lab 开关现状。
- `ai.workflow` 让 Agent 走一遍完整流程做示范。
- Lab 段直接显示当前是开是关（读插件存储，不信上下文记忆）。

**背后**：纯静态文案 + `labMode` 状态；不会替你打开 Lab。

### 3. 智库 Field documents

**回答**：随包的 334 篇文档在哪里、怎么查。

- 左侧目录树（按知识库 / 手册 / 工具文档 / 战例原文分组），右侧 Markdown 正文；战例原文与先例包同名，
  由包里的 `caseDocs` 指过来。
- 搜索框上方有 **Titles / Full text** 两个 chip：Titles 只对标题与路径过滤（瞬时），Full text 才扫正文
  （至少 2 个字符，扫描期间显示进度）。全文搜索只用来「找到哪篇」，要引用全文请让 Agent 走 `read_doc`。
- 窄面板下选中文档会把目录让位给正文，「返回」按钮把目录放回来。
- `ai.docs` 把「这批文档怎么用」的问题交给 Agent。

**背后**：`import.meta.glob` 惰性加载 Markdown，运行时不解包、不联网。

### 4. 战例库 Cases

**回答**：这个项目里哪些案例可复现、哪些还不能动、每个已经证明了什么；现成的方法先例有哪些。

- 上面一张表是你自己的案例：案例名（目录名）、预设、授权状态、是否就绪、范围内资产数、证据条目数、
  工作项完成度、最近更新。点案例名展开详情：`scope.md` 路径、网络姿态、决策记录条数、工作项进度、
  blocker 列表、范围内 / 交付物两列。
- 下面一张表是**随包先例库**：每个包的标题、`cases/<slug>/` 位置、建议起始预设、适用信号（前三个 + 计数）、
  文档数，以及一行 `范围待定`。它是方法，不是你的案例——复制一份重跑 `init_task` 才会出现在上面那张表里。
- 「Rescan」重新扫一次（新建案例或写完笔记后用）。
- 就绪标签是**重新推导**的，不读 `scope.md` 里那行 `- ready_for_act:`——手改那一行不会让未授权的
  案例变绿。

**边界**：页面**不写盘**。建案例用 `init_task`，记决策用 `record_case_note`，读正文用宿主文件工具。
索引只扫 `cases/` 与 `work/` 的直接子目录，超过 200 个会在页面顶部说明结论不完整。先例库是编译进
插件的静态表（`selectedPath` 这样按路径标识的做法只用于左侧本地案例）。

### 5. 活动 Activity

**回答**：这一轮对话里 Agent 跑了什么、出了什么结果。

- 按时间倒序列出工具结果与运行事件，标出「来自对话」。
- 「清空」只清面板的这份列表，不动磁盘、不动报告。

**背后**：`panel-channel` 的事件流；面板不主动调用工具。

### 6. 提示词 Prompt Library

**回答**：多套提示词怎么管理、当前注入的是哪一套。

- 左侧列表 + 右侧编辑器；「创建」「导入」「激活 / 停用」「删除」。
- 导入是**按文件**导入，同名或相似内容会提示冲突并计数，不静默覆盖。
- 激活的那一套才会注入对话；停用后回到默认。

**边界**：改的是插件私有存储里的提示词库，不碰宿主的系统提示。

## 二、分析组

### 7. 样本 Samples

**回答**：工作区里哪些文件可以分析、每种格式能解析出什么。

- 列出项目内可读文件（按大小与类型过滤），点一个就开始分析。
- 顶部路径框可以贴项目内路径。
- 三种边界写在页面上：**项目根边界**（读不到目录外）、**大小上限**（超限交对话）、**只读**
  （面板从不执行样本）。

**背后**：`bridge.stat` + `loadSample`；超过 `READ_LIMIT_BYTES` 或越界时提示交给 Agent。

### 8. 发现 Findings

**回答**：命中了哪些规则，最严重的排最前。

- 四个数字块：总数、高危（critical+high）、中危、干净。
- 严重度筛选 chip 带计数；每条发现可点「问 Agent」追问依据。
- `ai.explainAll` 让 Agent 解释整份发现列表。

**背后**：只读本次 `report.findings`，不重新分析。

### 9. 字符串 Strings

**回答**：样本里有哪些可打印字符串、按类型怎么分组。

- 过滤：最小长度、数量上限、类别（URL / 路径 / 标识符 / 全部）。
- 表格给偏移、类别、值；超过上限会明确说「已截断」。
- `ai.strings` 把筛出来的这批交 Agent 判断。

**边界**：本地计算，不联网、不做 IOC 富化。

### 10. 反汇编 Disassembly

**回答**：可执行段里的函数在哪、某个函数长什么样。

- 左列函数清单（含未命名 `sub_*`），可按名字过滤；点一个在右侧出控制流列表。
- 指令预算滑杆控制展开多少条；「复制」把当前列表拷走。
- 空态区分「没有可执行段」与「还没索引」。

**背后**：插件自己的线性扫描与伪 C，不依赖 IDA；需要深度反编译时用对话里的 `run_radare` /
IDA 桥。地址是**文件偏移**，不是虚拟地址。

## 三、取证组

### 11. 清单 Manifest

**回答**：申请了哪些权限、暴露了哪些组件。

- 权限按运行时风险分级（`internal` / 普通 / 危险），组件按暴露程度排序。
- 「导出」把这张表存成 Markdown；`ai.permissions` 让 Agent 讲清哪些权限组合最危险。

**边界**：解析的是清单事实，不代表运行时行为。

### 12. 熵 Entropy

**回答**：字节从哪里开始不像代码、开始像压缩或加密。

- 分桶柱状图 + 段表（段名 / 偏移 / 大小 / 熵值）；峰值与均值单独标出。
- 分桶数量可调（8–60），改的是设置，**下次分析生效**；当前图表不重算。
- `ai.entropy` 让 Agent 判「是壳、是资源、还是加密段」。

**边界**：熵是启发式，页面自己就这么写，不给判定。

### 13. 签名 Signature

**回答**：清单里显示哪几种签名方案。

- v1 / v2 / v3 三态逐条列出，另外单列清单里实际声明的方案名（`signature.schemes`）。
  页面**不展示证书指纹**——那是 `verify_signature` 的返回值，面板不重复一份可能过期的摘要。
- 页面明确写着**这不是密码学结论**：真要验签用对话里的 `verify_signature`（走 `apksigner`）。

### 14. 对比 Compare

**回答**：两个版本之间到底改了什么。

- 左右各选一份已分析样本；未选满两份时给的是「还缺一份」，不是空表。
- 三块对比：事实字段、权限、组件、发现；新增 / 移除 / 保留分别着色。
- 家族基线三列：共同 / 仅本样本 / 仅家族，并给每条规则在家族内出现份数。
- `ai.compare` 让 Agent 解读差异是否指向加固或功能变更。

## 四、系统组

### 15. 自检 Self check

**回答**：环境事实是什么样——哪些外部工具在、哪些被宿主拒绝、知识库与提示词是否就绪。

- 分组统计 + 失败项计数；每个工具给「未装 / 被拒 / 可用」三态。
- 「安装全部」不是真的装：它让 Agent 用 `install_toolchain` 拿本平台命令，再由你/宿主执行。
- `ai.toolchain` 讲清整体缺口。

**边界**：`BLOCKED`（宿主拒绝）与 `NOT_FOUND`（没装）是两句话，页面不混。

### 16. 报告 Reports

**回答**：这个面板分析过什么、产物落在哪、怎么交出去。

- 列出本次会话的报告（名字、风险分、格式、时间）。
- 「导出 Markdown / JSON」走宿主的另存为对话框；「复制」把正文拷到剪贴板。
- 存储状态分「已开启 / 未开启」：没开持久化时，刷新会丢列表——页面直说，不假装保存了。

### 17. 设置 Settings

**回答**：分析口径怎么调，什么时候生效。

- 分析模式（摘要 / 全量）、规则开关（关掉的规则不出现在发现里，但计入「未评估」）、扫描分辨率
  （最小串长、上限、熵分桶）。
- 运行时段显示 Lab 开关、当前提示词、工作区授权状态。
- 「重置」把上述设置恢复默认，不动报告与提示词库。

**边界**：改设置**不会**立刻重跑；页面写「下次分析生效」。

## 五、常见路径

| 想做的事 | 点哪里 |
|---|---|
| 第一次用，先看它能做什么 | 引导 → 「走一遍」 |
| 快速看一个包有多危险 | 样本 → 点文件 → 总览 |
| 只想知道危险权限 | 样本 → 清单 → 危险权限段 |
| 判断是不是加了壳 | 取证 → 熵（看峰值段）→ 问 Agent |
| 确认签名是不是原厂 | 签名（看方案）→ 对话 `verify_signature`（拿结论） |
| 两个版本比一比 | 各分析一次 → 对比 → 左右各选一份 |
| 把结论交出去 | 报告 → 导出 Markdown / JSON |
| 建一个可复现的案件 | 对话 `init_task` → 战例库 Rescan 看它就绪没 |
| 复用以前做过的事 | 战例库（看已有案例）→ 对话 `search_cases`（按关键词） |
| 手上这个形状以前怎么做的 | 战例库下面那张「先例库」表 → 读 `cases/<slug>/docs/method.md` |
| 记下「为什么否掉某个方案」 | 对话 `record_case_note`，`status=rejected` |

## 六、面板做不到的

- **不执行样本**：面板永不运行被分析的文件。
- **不碰项目外文件**：读不到工作区目录外的路径，这是宿主边界。
- **不自动装工具**：安装命令由你/宿主在实名下执行。
- **不替你判断授权**：案件能不能动由 `scope.md` 推导，面板只显示推导结果。
- **静态优先**：只在运行期出现的行为要靠对话里的 Frida 补充，面板不猜。
