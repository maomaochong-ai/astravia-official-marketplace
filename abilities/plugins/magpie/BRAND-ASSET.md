# Brand asset

`assets/icon.png` 是 magpie 上游仓库自带的品牌图，原样拷贝，未做任何重绘、裁切或调色。

| 项 | 值 |
| --- | --- |
| 来源文件 | `site/public/img/icon-256.png`（仓库 `github.com/yetone/magpie`） |
| 站点声明 | `site/public/index.html` 以 `<link rel="apple-touch-icon" href="/img/icon-256.png">` 引用同一文件 |
| 抓取日 | 2026-11-08 |
| 尺寸 | 256 × 256，8-bit RGBA PNG，非交错 |
| 字节数 | 6619 |
| SHA-256 | `57437c6596e05a8fcfc42d4288c030aa00ed86b69fe35d464d69d7026150c704` |
| 权利归属 | magpie 项目及其作者（仓库声明 MIT） |

不使用 Iconify 里的近似图形替代：这是有独立品牌标识的能力，卡片图标必须是官方位图。

侧边栏图标另用 iconify 类名（`icon-[solar--routing-2-linear]`），因为宿主会给导航图标按主题着色，彩色 logo 在那里会被压成单色。
