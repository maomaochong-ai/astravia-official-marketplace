## `tangping-editorial-perspective.md`

An editorial reading of the public argument over "lying flat" (躺平), built with contradiction analysis: it separates the observable facts (employment, income, working hours, distribution expectations) from the labels applied to them, and argues that the strongest explanation is the one that stays closest to the investigation.

- Figures and quotes in the case are the author's; the package does not vouch for them.
